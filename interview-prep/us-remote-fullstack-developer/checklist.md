# 7-Day Interview Prep Checklist: Full-Stack Developer (US Remote)

## Day 1: React & Frontend Basics
- [ ] Review React Hooks (`useState`, `useEffect`, `useContext`).
- [ ] Practice building a responsive layout using Flexbox or Grid.
- [ ] Study React performance optimization (Memoization).

## Day 2: React Native & Mobile
- [ ] Review React Native core components (`View`, `Text`, `FlatList`).
- [ ] Study React Navigation (Stack and Tab navigators).
- [ ] Understand the differences between Web and Mobile event handling.

## Day 3: Backend & API Design
- [ ] Review Node.js (Express) or Python (FastAPI/Flask) basics.
- [ ] Practice building a CRUD API with authentication (JWT).
- [ ] Study RESTful API best practices and status codes.

## Day 4: Databases (SQL & NoSQL)
- [ ] Review PostgreSQL/MySQL: Joins, Indexes, and ACID properties.
- [ ] Review MongoDB: Collections, Documents, and Aggregation.
- [ ] Practice writing a database migration script.

## Day 5: Docker & Cloud Infrastructure
- [ ] Write a `Dockerfile` for a React + Node app.
- [ ] Experiment with `docker-compose` to run an app and a database together.
- [ ] Review AWS/GCP basics (Compute, Storage, Managed DBs).

## Day 6: Security & System Design
- [ ] Review JWT (Sign/Verify) and Refresh Token flows.
- [ ] Study common web vulnerabilities (XSS, CSRF, SQL Injection).
- [ ] Design a high-level system for a simple "Task Manager" or "Chat App."

## Day 7: US Culture & Communication
- [ ] Formulate your "Remote Work" success stories (Ownership, Transparency).
- [ ] Practice explaining complex technical concepts clearly in English.
- [ ] Final review of the "Frontend" and "Backend" deep-dives.
