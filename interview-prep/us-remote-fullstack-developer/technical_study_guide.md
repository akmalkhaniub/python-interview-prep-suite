# Technical Study Guide: Full-Stack Developer (US Remote)

## 1. Frontend & Mobile (React & RN)
- **React.js Hooks:** `useState`, `useEffect`, `useMemo`, and custom hooks.
- **State Management:** Redux Toolkit, Zustand, or React Context API.
- **React Native:**
    - Navigation (React Navigation).
    - Image and List optimization (`FlashList` / `FlatList`).
- **Styling:** CSS-in-JS (Styled Components) or Tailwind CSS.

## 2. Backend Development (Node/Python)
- **Node.js:** Express.js, async/await patterns, and middleware design.
- **Python:** FastAPI or Django REST Framework.
- **Microservices:** Service communication (REST, gRPC, or Message Queues).
- **Security:** Handling CORS, Rate Limiting, and SQL Injection prevention.

## 3. Databases & Data Modeling
- **PostgreSQL / MySQL:**
    - Normalization vs. Denormalization.
    - ACID properties.
    - Joins and Subqueries.
- **MongoDB:**
    - Document modeling.
    - Aggregation pipelines.
- **Redis:** Basic caching strategies.

## 4. Cloud & DevOps
- **Docker:** Writing a `Dockerfile` and `docker-compose.yml`.
- **AWS/GCP Basics:**
    - EC2 / Cloud Run (Compute).
    - RDS / Cloud SQL (Managed DBs).
    - S3 / GCS (Storage).
- **CI/CD:** GitHub Actions or GitLab CI basics.

## 5. System Design & API Integration
- **RESTful Principles:** Status codes, HTTP verbs, and versioning.
- **JSON Web Tokens (JWT):** The sign/verify process and refresh token strategies.
- **Performance Profiling:** Lighthouse for Web, Flipper for Mobile.
