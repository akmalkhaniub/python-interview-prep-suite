# JD Analysis: Software Engineer II (NCR Atleos)
## Role: Enterprise .NET Specialist | Focus: Self-Service & Financial Access

### 1. The Enterprise Context
NCR Atleos is a global leader in self-service financial tech (ATMs, Retail kiosks). This means your software isn't just running on a server; it's running on **thousands of distributed endpoints** globally.
- **Reliability:** The cost of a bug is high when it impacts physical hardware across different time zones.
- **Legacy + Modern:** You'll work with core .NET/IIS stacks while integrating modern React/Angular frontends.

### 3. Key Differentiators: The "II" Level Expectations
As a Software Engineer II (4-7 years), you are expected to:
- **Operate with Minimal Supervision:** You own features from requirements to building.
- **Continuous Improvement:** You don't just fix bugs; you perform **Root Cause Analysis** to prevent them from recurring.
- **Troubleshooting Expert:** You are the go-to person for complex production issues and performance tuning on IIS.
