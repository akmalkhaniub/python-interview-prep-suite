# Full-Stack AI Engineer (TypeScript) at Caliberly (on behalf of AI-native Startup)

## About the job
**Location:** Abu Dhabi, United Arab Emirates (Remote-First / Global Remote)
**Hiring Agency:** Caliberly (Hiring on behalf of a venture-backed stealth startup building an AI-native desktop platform)

### Role Overview
We are looking for a highly skilled Full-Stack AI Engineer with a strong background in the TypeScript ecosystem. You will be responsible for designing and shipping a state-of-the-art, AI-native desktop product (in the vein of Cursor, Raycast, or Granola) that integrates deeply with local operating systems, local developer toolsets, and remote LLM orchestrations. 

In this role, you will own the full engineering lifecycle: from writing backend API integrations in NestJS, defining agentic loops and local vector embeddings (ChromaDB), building responsive user interfaces in React 19, to packaging the application into a lightweight desktop shell using Tauri v2.

---

### Core Responsibilities
- **AI/LLM Application Development:** Design and build advanced AI agentic systems using LangChain, custom prompt structures, and the Model Context Protocol (MCP) SDK.
- **RAG & Vector Embeddings:** Implement low-latency Retrieval-Augmented Generation (RAG) workflows using ChromaDB 3, employing HNSW indexing for rapid semantic lookups over local files.
- **Full-Stack Implementation:** Deliver scalable APIs in NestJS 11 / Node.js 22 running on Bun, and construct intuitive, fluid interfaces in React 19 using MUI 7 and Zustand.
- **Desktop System Integration:** Maintain and optimize the desktop application shell using Tauri v2, bridging native OS APIs with frontend views and managing local files and execution environments.
- **Real-Time Data Streaming:** Build low-latency, real-time message streaming over WebSockets and Socket.IO for token-by-token LLM output rendering.
- **Quality & Resilience:** Maintain high test coverage using Vitest 3 and Playwright, and enforce runtime reliability through mutation testing using Stryker.

---

### Must-Have Technical Stack & Qualifications
- **Programming Language:** 3–4+ years of professional production-grade experience with TypeScript.
- **Runtime Environment:** Proficient with Node.js 22 and Bun toolchains.
- **Frontend Stack:** Extensive experience with React 19, state management via Zustand, Vite 7, and styling via MUI 7.
- **Backend Stack:** Expert-level knowledge of NestJS 11 and Socket.IO for real-time WebSocket communication.
- **AI Stack:** Hands-on experience building LLM pipelines, prompt chains, LangChain, vector databases (specifically ChromaDB 3), and Model Context Protocol (MCP) client/server implementations.
- **Desktop Frameworks:** Prior experience packaging web apps with Tauri (v2 preferred) or Electron.
- **Testing Frameworks:** Experience writing robust tests using Vitest 3, Playwright, and running mutation tests using Stryker.
- **Portfolio:** A strong GitHub profile showing production-grade or complex side projects integrating AI agents, desktop wrappers, or full-stack TypeScript systems.
