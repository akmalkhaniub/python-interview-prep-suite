# 7-Day Interview Prep Checklist: Principal React Native Engineer (Creative Chaos)

## Day 1: React Native Architecture Deep Dive
- [ ] Study the **New Architecture** (Fabric, TurboModules, JSI).
- [ ] Understand the differences between **Hermes** and **V8/JSC**.
- [ ] Review the **Fabric** rendering pipeline and shadow tree concepts.

## Day 2: Native Bridge & Integration
- [ ] Practice writing a simple **Native Module** (Objective-C/Swift for iOS and Java/Kotlin for Android).
- [ ] Review **JSI** implementation patterns and performance benefits.
- [ ] Study the **Bridgeless Mode** in RN 0.73+.

## Day 3: GraphQL & Advanced Data
- [ ] Review **Apollo Client** cache management and normalization.
- [ ] Practice designing a **GraphQL schema** for a complex mobile feature (e.g., a real-time messaging system).
- [ ] Study **Offline Storage** solutions (MMKV, WatermelonDB, SQLite).

## Day 4: Performance & Optimization
- [ ] Use **FlashList** in a sample project and compare performance with FlatList.
- [ ] Study **Memory Profiling** in Xcode and Android Studio.
- [ ] Review **Image Optimization** and caching libraries (FastImage).

## Day 5: System Design & Patterns
- [ ] Review **Mobile Design Patterns** (MVVM, Clean Architecture).
- [ ] Design a **Modular Architecture** for a multi-tenant mobile app.
- [ ] Study **Security Best Practices** (SSL Pinning, Keychain, Obfuscation).

## Day 6: Leadership & Mentorship
- [ ] Formulate stories for **Conflict Resolution** and **Mentorship**.
- [ ] Review **Estimation Techniques** (Story points, PERT).
- [ ] Prepare for **Client Communication** scenarios and technical status reporting.

## Day 7: Strategic Review & Mock Interviews
- [ ] Final review of **Design Patterns** and **Architecture** docs.
- [ ] Prepare questions for the interviewers (Hiring process, technical vision).
- [ ] Conduct a mock interview focused on **Principal-level scenarios**.
