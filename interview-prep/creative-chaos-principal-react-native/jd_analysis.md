# Job Description Analysis: Principal React Native Engineer - Creative Chaos

## Role Overview
**Company:** Creative Chaos
**Position:** Principal Software Engineer (React Native)
**Experience:** 6-10 years.
**Core Mission:** Lead mobile development, mentor engineers, and bridge the gap between high-level React Native and underlying Native APIs.
**Key Differentiator:** Strong emphasis on "Transitioned from native iOS/Android" and "rendering components with Native APIs."

## Core Competencies

### 1. Advanced React Native & Native Bridge
- **Native Integration:** Deep understanding of Objective-C, Swift, Java, or Kotlin to write native modules.
- **Performance:** Tuning code for security and performance at the native layer.
- **Rendering:** High proficiency in native rendering patterns beyond basic React components.

### 2. Modern Frontend Stack
- **Languages:** TypeScript (expert level).
- **Data:** GraphQL and REST APIs.
- **Storage:** Offline storage strategies and document request models.
- **Styling:** CSS/HTML proficiency for cross-platform compatibility.

### 3. Leadership & Soft Skills
- **Team Leadership:** Leading a team of software engineers.
- **Mentorship:** Continuous training and guidance for team members.
- **Hiring:** Evaluating candidates for open positions.
- **Communication:** Client interaction and status reporting.

### 4. Engineering Excellence
- **Design Patterns:** Knowledge and application of mobile design patterns (MVVM, Clean Architecture).
- **Process:** JIRA, GitHub, estimation, and requirement analysis.

## Key Interview Themes to Prepare

1.  **The New Architecture (JSI/TurboModules):** Explaining how the React Native bridge is evolving and how native modules are implemented today.
2.  **Native-to-RN Transition:** Discussing the trade-offs when migrating a legacy native app to React Native.
3.  **Performance Optimization:** How to profile a React Native app (Hermes, Flipper, Native profiling tools) and fix frame drops or memory leaks.
4.  **Offline-First Strategy:** Designing robust offline storage using WatermelonDB, SQLite, or Realm.
5.  **Engineering Leadership:** Scenarios involving mentoring junior developers, handling conflict, or setting technical standards.
6.  **GraphQL in Mobile:** Efficient query design, caching strategies (Apollo/Urql), and handling real-time updates (Subscriptions).

## Technical "Must-Haves" for the Interview
- Ability to explain a complex Native Module you built.
- Strong opinions on State Management (Zustand, Redux, Context API).
- Experience with CI/CD for mobile (Fastlane, Bitrise, GitHub Actions).
