# Interview Prep Checklist: Senior Full Stack Engineer (Deel)

Use this checklist to track your preparation progress for the Deel interview.

## 🏁 Phase 1: Fundamentals & Review
- [ ] Review [JD Analysis](jd_analysis.md) to align on core expectations.
- [ ] Read through the [Study Guide](study_guide.md) (All 6 sections).
- [ ] Refresh on TypeScript 5.x features (Decorators, Template Literal Types).
- [ ] Review React 18/19 features (Concurrent Rendering, Server Components).

## 💻 Phase 2: Technical Deep Dive
- [ ] **Frontend**: Implement a complex component with custom hooks and performance optimization.
- [ ] **Backend**: Build a small NestJS or Express service with typed controllers and middleware.
- [ ] **Database**: Practice writing complex SQL queries (Joins, Aggregations, JSONB).
- [ ] **Testing**: Write unit tests with Jest and a sample E2E test with Cypress.

## 🏗️ Phase 3: System Design & SaaS
- [ ] Draft a high-level architecture for a "Global Payroll System".
- [ ] Understand idempotency in financial systems.
- [ ] Research Deel's core products (EOR, Global Payroll, Contractor Management).

## 🤝 Phase 4: Soft Skills & Culture
- [ ] Prepare 3 "STAR" method stories demonstrating **Ownership**.
- [ ] Prepare a story about working in a **remote-first** or asynchronous environment.
- [ ] Research Deel's mission and recent company news (e.g., funding, acquisitions).

## 🚀 Final Countdown
- [ ] Complete the [Coding Challenges](coding_challenges.ipynb).
- [ ] Mock Interview: Practice explaining your architecture decisions out loud.
- [ ] Check Deel's Engineering Blog (if available) for recent technical challenges.
