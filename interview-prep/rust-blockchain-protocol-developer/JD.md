# Rust Blockchain Protocol Developer

## About the job
**Location: Remote (Worldwide)**

### Role Description
We are seeking an experienced **Senior Rust Blockchain Protocol Developer** to join our Core Ledger Engineering team. In this role, you will design, optimize, and secure low-level blockchain infrastructure, including virtual machine runtimes (EVM/WASM interpreters), P2P networking protocols, memory-efficient state databases, and cryptographic primitives. You will write high-performance, audit-ready Rust code to power a scalable, secure, and decentralized ledger.

### Key Responsibilities
- **Core Protocol Engineering:** Develop and maintain core node components: state transition engines, execution clients, transaction pools, and RPC interfaces in Rust.
- **Runtime Optimization:** Benchmark and optimize virtual machine execution speed (e.g., EVM interpreters like REVM, or custom WASM runtimes) and state database performance.
- **Network Programming:** Scale and optimize peer-to-peer (P2P) networking protocols using libp2p and manage message routing algorithms.
- **Applied Cryptography:** Implement and optimize signature verification, hashing algorithms, and zero-knowledge proof circuits using memory-safe Rust primitives.
- **Security & Benchmarking:** Conduct stress tests, write extensive unit and integration suites, and audit code against memory safety and denial-of-service vulnerabilities.

### Requirements
- **Rust Mastery:** 4+ years of professional experience building systems-level software in **Rust**, with a deep understanding of lifetime management, memory safety, and thread concurrency.
- **Protocol Engineering:** 2+ years of experience working directly on core blockchain node protocols (e.g., Ethereum client development, Substrate pallets, Cosmos SDK, or Solana VM).
- **Network & Cryptography Knowledge:** Strong understanding of P2P networking concepts (TCP/UDP, NAT traversal, DHTs) and cryptographic primitives (ECDSA, Ed25519, SHA3/Keccak).
- **Databases & State:** Experience working with high-performance key-value databases like RocksDB or LevelDB in the context of state-trie storage.
- **Academic Background:** Degree in Computer Science, Mathematics, or equivalent systems-level practical experience.
