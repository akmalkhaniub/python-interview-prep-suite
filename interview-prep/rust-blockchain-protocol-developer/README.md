# Rust Blockchain Protocol Developer Prep

This module contains preparation materials for the **Rust Blockchain Protocol Developer** role. The curriculum covers systems-level Rust programming, WebAssembly and EVM execution runtimes, P2P networking (libp2p), and high-performance state databases (RocksDB).

## Contents
- [JD.md](file:///g:/ReplitProjects/telemedicine/python-engineer-notebooks/interview-prep/rust-blockchain-protocol-developer/JD.md): The job description and core requirements.
- [01-rust-runtime-evm.md](file:///g:/ReplitProjects/telemedicine/python-engineer-notebooks/interview-prep/rust-blockchain-protocol-developer/01-rust-runtime-evm.md): Rust-based execution environments, WASM runtimes (Substrate), EVM interpreters in Rust (revm), state databases (RocksDB), and memory layouts.
- [02-networking-consensus-cryptography.md](file:///g:/ReplitProjects/telemedicine/python-engineer-notebooks/interview-prep/rust-blockchain-protocol-developer/02-networking-consensus-cryptography.md): libp2p P2P networking, consensus engine implementation (BFT, PoS), cryptographic signatures (Ed25519) in Rust, and memory safety vulnerabilities (panic vectors, DOS vectors).
