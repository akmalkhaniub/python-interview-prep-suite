# Compound AI Systems Architect

## About the job
**Location: New York, NY / Remote**

### About the Company
We build state-of-the-art enterprise workflow automation platforms. Instead of relying on single monolithic LLM requests, our architecture is designed as a **Compound AI System**—combining multiple models, advanced retrieval components (RAG), dynamic supervisor routing, and deterministic program loops to solve complex, multi-step business logic with high accuracy and predictability.

### Role Overview
We are looking for a **Compound AI Systems Architect** to lead the structural design of our multi-agent automation pipelines. In this role, you will transition our prototypes from single-prompt LLM scripts into mature, deterministic systems. You will design state machine orchestrations, define routing algorithms, optimize retrieval components, and implement rigor-filled evaluation frameworks. You will bridge software engineering and AI systems, driving reliability, efficiency, and scalability in our production applications.

### Key Responsibilities
- **System Architecture & Orchestration:** Architect robust multi-agent topologies (supervisor, sequential, peer-to-peer networks) using frameworks like LangGraph, CrewAI, or specialized internal state engines.
- **System-Level Optimization:** Utilize systems like DSPy to programmatically optimize prompt formatting, weights, and retrieval behaviors across composite pipelines.
- **Evaluation & Benchmarking:** Design and execute high-throughput validation pipelines using "golden datasets" and LLM-as-a-judge patterns to detect regression in agent behaviors.
- **Caching & Latency Engineering:** Implement token caching strategies, parallelized request paths, and model fallback logic to manage system latency and API expenditures.
- **Data & Context Routing:** Design hybrid RAG pipelines with semantic routers, query rewrites, re-ranking systems, and metadata filters to maximize retriever accuracy.

### Must-Have Qualifications
- **Systems Engineering Background:** 6+ years of experience in distributed systems, software architecture, or backend engineering.
- **LLM Orchestration Experience:** 2+ years of hands-on experience building complex agentic systems (e.g., LangGraph, AutoGen) or stateful application workflows.
- **Optimization & Evaluation Literacy:** Practical experience with evaluation frameworks (e.g., Ragas, Langfuse, DeepEval) and data-driven prompt optimization.
- **Strong Language Fundamentals:** Expert-level programming skills in **Python**.
- **Data Engineering Knowledge:** Professional experience with vector databases (Pinecone, Qdrant, Milvus) and query performance tuning.

### Nice-to-Have Qualifications
- Experience with DSPy (Declarative Self-improving Language Programs) or similar prompt compiler frameworks.
- Background in distributed execution engines like Temporal.io or Celery.
- Academic or professional background in Machine Learning and Natural Language Processing.
