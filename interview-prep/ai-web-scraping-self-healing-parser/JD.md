# AI Web Scraping & Self-Healing Parser Engineer

## About the job
**Location: Remote (Worldwide)**

### Role Description
The standard paradigm of web scraping using rigid CSS classes, XPath queries, and manual layout patching is obsolete. We are hiring a **Senior AI Web Scraping & Self-Healing Parser Engineer** to build and operate autonomous data extraction agents. In this role, you will design systems that combine browser automation with vision-language models and LLM parsers to create "self-healing" extraction loops that dynamically adapt to layout changes, structural redesigns, and interactive anti-bot systems.

### Key Responsibilities
- **Self-Healing Selector Pipelines:** Build automated selector-healing pipelines that detect extraction degradation and use semantic analysis to auto-correct target DOM selectors.
- **LLM-Based Data Extraction:** Design and implement zero-shot schema extraction agents using LLMs and multimodal models to parse complex web interfaces (such as SPAs and dynamic dashboards) without hardcoded rules.
- **Visual Web Extraction:** Implement computer vision models to identify functional page elements (buttons, inputs, prices) by visual appearance rather than raw HTML markup.
- **Robust Pipeline Scaling:** Maintain high-throughput scraper worker clusters executing millions of extraction runs daily, optimized for latency, cost, and reliability.
- **Data Quality & Validation:** Enforce real-time schema validations and anomaly detection algorithms to guarantee the purity and reliability of ingested data feeds.

### Requirements
- **Professional Experience:** 5+ years of software engineering experience in backend development, distributed data pipelines, or high-throughput scraping environments.
- **Stealth Automation:** Hands-on experience with Playwright or Puppeteer, including running browsers in stealth configurations to bypass bot detection.
- **AI/LLM Engineering:** Experience integrating LLMs (OpenAI, Anthropic APIs) or local vision-language models (e.g., LLaVA) for semantic data extraction.
- **Python / JS Proficiency:** Strong expertise in **Python** (asyncio, FastAPI, Pydantic) and **JavaScript/TypeScript**.
- **Data Architecture:** Practical experience with message queues (Kafka, Celery) and unstructured databases (MongoDB, Elasticsearch, Postgres JSONB).
