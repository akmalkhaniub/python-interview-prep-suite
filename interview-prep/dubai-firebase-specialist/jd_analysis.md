# Job Description Analysis: Full-Stack Firebase Specialist (Dubai/Remote)

## Role Overview
**Company:** Dubai-based Startup (Restaurant/SaaS domain implied by "kitchen, franchise HQ").
**Position:** Full-Stack Firebase Specialist (React + Firebase + PWA).
**Experience:** 3-6 years.
**Core Stack:** Firebase (Firestore, Cloud Functions, Auth, FCM, PWA).
**Key Differentiator:** Expert-level Firebase knowledge is mandatory; this is a "build without hand-holding" role.

## Core Competencies

### 1. Firebase Ecosystem (Expert Level)
- **Firestore:** Multi-tenant architecture, complex queries, security rules.
- **Cloud Functions:** Webhook processing, aggregation, scheduled reports.
- **Auth:** Multi-role systems (RBAC).
- **FCM:** Cross-platform push notifications (Web, Android, iOS PWA).

### 2. Frontend & PWA
- **React.js:** Wiring live data with real-time listeners and auth guards.
- **PWA:** Service workers, offline caching, and "Add to Home Screen" manifests.
- **Arabic RTL:** Knowledge of RTL layout for the UAE market (Big advantage).

### 3. Integrations & Webhooks
- **External APIs:** WhatsApp Business API (360dialog), Payment Gateways (Tap, Stripe).
- **Security:** HMAC validation for webhooks and error handling.
- **Tools:** GitHub production deployment discipline.

### 4. Professional Experience
- **SaaS:** Built and shipped at least 1 multi-tenant application.
- **Production:** At least 2 live Firebase projects in production.
- **Integrations:** Completed at least 3 REST API or webhook integrations.

## Key Interview Themes to Prepare

1.  **Multi-tenant Firestore Strategy:** How to structure collections and security rules for a franchise HQ vs. individual restaurant managers.
2.  **HMAC & Webhook Security:** Explaining the process of validating incoming webhooks from payment gateways or WhatsApp.
3.  **PWA Offline Reliability:** Strategies for offline caching and data synchronization when a restaurant's internet goes down.
4.  **Cloud Functions Scalability:** Handling aggregator normalization and scheduled reporting without hitting function execution limits.
5.  **Arabic RTL Implementation:** Best practices for CSS `direction: rtl` and React component adaptation for the Middle East market.
6.  **Independent Research:** Be ready to discuss a time you researched a new API (e.g., WhatsApp/360dialog) and built a solution without guidance.

## Technical "Must-Haves" for the Interview
- Deep understanding of **Firestore Security Rules**.
- Experience with **Firebase Admin SDK** in Node.js.
- Strong knowledge of **Service Workers** lifecycle.
- Clear explanation of a **HMAC validation** implementation.
