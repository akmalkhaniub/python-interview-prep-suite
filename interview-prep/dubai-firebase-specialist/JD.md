About the job
Must-have skills
We will test every one of these in the interview. Do not apply if you have not shipped real production projects using these tools.

Firebase Firestore — expert level. Multi-tenant architecture, real-time listeners, security rules, complex queries
Firebase Cloud Functions (Node.js / TypeScript) — all backend logic lives here: webhook processing, aggregator normalisation, notification triggers, scheduled reports
React.js — wiring Claude-built components to live Firestore data with auth guards and real-time state
Progressive Web App (PWA) — service workers, offline caching, web app manifest, home screen install
REST API integration — you have integrated 3+ external APIs with webhooks, HMAC validation, and error handling
WhatsApp Business API — or strong webhook experience and willingness to learn 360dialog fast
Payment gateway integration — any gateway (Tap by Mastercard, Stripe, or equivalent)
Firebase Auth + role-based access — multi-role systems (manager, server, kitchen, franchise HQ)
Firebase Cloud Messaging (FCM) — push notifications across web, Android, and iOS PWA
Git / GitHub — clean commit history, branching strategy, production deployment discipline

Good to have:
Arabic RTL layout in CSS and React (big advantage for UAE market)
Capacitor / Ionic — for native iOS/Android App Store wrapping
Twilio SMS API
QuickBooks or Xero API integration
Next.js (for SEO-ready restaurant ordering pages)

Experience we are looking for:
3–6 years full-stack development experience
At least 2 live Firebase / Google Cloud projects in production
At least 1 SaaS or multi-tenant application built and shipped
At least 3 REST API or webhook integrations completed
Comfortable working independently — you research, decide, and build without hand-holding
English communication — written and spoken, sufficient for daily async with Dubai-based founder
