# 7-Day Interview Prep Checklist: Firebase Specialist (Dubai)

## Day 1: Firestore Security & Multi-tenancy
- [ ] Practice writing complex **Firestore Security Rules** for multiple roles (Manager, Kitchen, HQ).
- [ ] Study the **Distributed Counter** pattern for high-frequency writes.
- [ ] Research **Multi-tenant architecture** patterns in Firestore.

## Day 2: Cloud Functions & Webhooks
- [ ] Practice implementing **HMAC Signature Validation** in a Cloud Function (Node.js).
- [ ] Review **Scheduled Functions** and aggregation patterns.
- [ ] Study **Firebase Admin SDK** for managing roles and sensitive data.

## Day 3: PWA & Offline Caching
- [ ] Review **Service Worker** lifecycles and Workbox caching strategies.
- [ ] Practice configuring a `manifest.json` for "Add to Home Screen" support.
- [ ] Test **Firestore Offline Persistence** in a sample React app.

## Day 4: FCM & Real-time UI
- [ ] Review **FCM Web Push** implementation and background messaging.
- [ ] Practice wiring a React app to Firestore using `onSnapshot` real-time listeners.
- [ ] Study the **App Shell** model for fast PWA loading.

## Day 5: Integrations (WhatsApp & Payments)
- [ ] Research the **WhatsApp Business API (360dialog)** webhook structure.
- [ ] Review **Stripe or Tap** payment gateway integration flows.
- [ ] Practice handling async payment successes via webhooks.

## Day 6: Arabic RTL & Deployment
- [ ] Study **CSS Logical Properties** for RTL layouts (`margin-inline-start`, etc.).
- [ ] Review best practices for **Arabic typography** in Web apps.
- [ ] Practice setting up a **GitHub Action** to deploy to Firebase.

## Day 7: Pitch & Final Review
- [ ] Prepare your "2-3 sentence project description" for the application LinkedIn message.
- [ ] Final review of the **HMAC validation** and **Security Rules** deep-dives.
- [ ] Mock technical screen: Explain your most complex Firebase project and the "why" behind your architecture choices.
