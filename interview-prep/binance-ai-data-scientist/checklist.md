# Interview Prep Checklist: AI & Data Scientist (Binance)

## Phase 1: Agentic Tools & RAG (Days 1-2)
- [ ] **Hands-on with Dify/n8n/Coze:** Build a simple agent that retrieves information from a crypto whitepaper.
- [ ] **Master RAG:** Review vector database selection, chunking, and re-ranking techniques.
- [ ] **Prompt Engineering:** Practice systematic prompt optimization (few-shot, CoT).

## Phase 2: ML & Model Optimization (Days 3-4)
- [ ] **Fine-tuning Review:** Understand the LoRA/PEFT process for financial document processing.
- [ ] **Hyperparameter Tuning:** Review techniques for optimizing model performance.
- [ ] **Python/PyTorch/HF:** Refresh your skills in using the Hugging Face ecosystem for model deployment.

## Phase 3: Crypto Data & Statistics (Days 5-6)
- [ ] **Blockchain Analytics:** Refresh your SQL skills for querying transaction data.
- [ ] **Time-Series & Forecasting:** Review statistical methods relevant to market data.
- [ ] **Bilingual Prep:** Practice explaining technical LLM concepts in both English and Mandarin.

## Phase 4: Final Strategy & STAR (Day 7)
- [ ] **STAR Stories (AI Focus):** Prepare stories on deploying LLM applications that improved team efficiency.
- [ ] **Culture Check:** Research Binance's mission and how you align with the "freedom of money" objective.
- [ ] **System Design:** Whiteboard a scalable AI assistant architecture for a global crypto exchange.

---
**Key Terms to Master:**
- **Dify/n8n/Coze:** Agent orchestration tools.
- **RAG:** Retrieval-Augmented Generation.
- **PEFT/LoRA:** Efficient fine-tuning.
- **Blockchain Ecosystem:** The infrastructure of digital assets.
