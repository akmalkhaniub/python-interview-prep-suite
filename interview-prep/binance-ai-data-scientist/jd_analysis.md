# Job Description Analysis: AI & Data Scientist - Binance

## Role Overview
**Company:** Binance (Global Blockchain Ecosystem)
**Position:** AI & Data Scientist
**Location:** Global / Remote focus.
**Focus:** LLM Applications, Agentic Models, Prompt Engineering, Crypto Infrastructure.
**Level:** 5+ years experience.
**Language:** Fluent in **English and Chinese** (Mandarin).

## Core Competencies

### 1. AI-Driven Initiatives & LLMs
- **Applications:** Design, development, and deployment of LLM applications and agentic models.
- **Tools:** Proficient in agent builders like **Dify**, **n8n**, or **Coze**.
- **Techniques:** Retrieval-Augmented Generation (RAG), Model fine-tuning, and Hyperparameter tuning.

### 2. Prompt Engineering & Optimization
- **Development:** Utilizing prompt engineering and model selection for key product features.
- **Optimization:** Fine-tuning and optimizing LLM performance for specific business scenarios (e.g., forecasting, process optimization).

### 3. Data Science & Statistical Modeling
- **Insights:** Extracting value from large-scale crypto datasets.
- **Modeling:** Applying data science methods for forecasting and optimization.
- **Visualization:** Transforming complex results into actionable recommendations for business decision-making.

### 4. Collaboration & Language
- **Cross-functional:** Working with global teams to gather requirements and deliver solutions.
- **Bilingual:** Seamlessly switching between English and Chinese in technical and business discussions.

## Key Requirements
- **Experience:** 5+ years in data science/analysis.
- **Stack:** Python, SQL, PyTorch, TensorFlow, Hugging Face.
- **Crypto Context:** Understanding the fast-paced, mission-driven crypto environment.

## Interview Themes to Prepare
1.  **Agentic Workflows in Crypto:** Designing an agent using Dify or n8n to automate customer support or trade analysis.
2.  **Multilingual RAG:** Implementing a RAG system that handles technical whitepapers and user queries in both English and Chinese.
3.  **Model Fine-tuning for Planning:** Discussing a project where you fine-tuned an LLM for planning-related tasks or complex decision-making.
4.  **Scaling AI at Binance:** How to optimize LLM latency and cost for an application serving millions of global crypto users.
5.  **Data Analysis in Blockchain:** Using SQL and Python to detect market trends or abnormal trading patterns on the exchange.
6.  **Prompt Engineering Strategy:** Your systematic approach to optimizing prompts (e.g., using A/B testing for prompts or automated evaluation).
