# Technical Study Guide: AI & Data Scientist (Binance)

## 1. LLM Agents & Orchestration Tools

### No-Code/Low-Code Agent Builders
- **Dify:** Understanding its workflow orchestration, knowledge base integration, and API capabilities.
- **n8n:** Automating workflows between LLMs and external services (e.g., Telegram, Slack, Database).
- **Coze:** Using its plugin system and workflow triggers for rapid agent development.

### Agentic Patterns
- **ReAct (Reasoning and Acting):** How agents decide which tool to call.
- **Memory Management:** Long-term vs. short-term memory in agents.
- **Task Decomposition:** Breaking down complex business requests into actionable steps for the LLM.

## 2. Advanced LLM Techniques

### RAG (Retrieval-Augmented Generation)
- **Vector Databases:** Using Pinecone or Milvus to store crypto-related knowledge.
- **Retrieval Optimization:** Hybrid search and re-ranking for accuracy in technical crypto queries.

### Model Fine-tuning
- **PEFT/LoRA:** Efficiently fine-tuning models like Llama or Mistral for specific planning tasks.
- **Instruction Tuning:** Training models to follow Binance-specific business logic.

## 3. Data Science & Blockchain Analytics

### Statistical Modeling
- **Time-Series Forecasting:** Predicting trade volumes or market volatility using classical and ML methods.
- **Anomaly Detection:** Identifying potential security threats or market manipulation in crypto datasets.

### Python/SQL for Scale
- **Optimizing SQL:** Querying terabyte-scale transaction logs efficiently.
- **Parallel Processing:** Using Dask or Multiprocessing in Python for large-scale data analysis.

## 4. Cross-Lingual & Strategic Communication

### Bilingual Technical Discussions
- **Mandarin Crypto Terminology:** Reviewing terms for "Blockchain," "Exchange," "Smart Contract," "Liquidity," etc.
- **Global Strategy:** Aligning AI initiatives with the mission of "increasing the freedom of money."

1. "How would you build an LLM agent to monitor market sentiment in real-time across English and Chinese social media?"
