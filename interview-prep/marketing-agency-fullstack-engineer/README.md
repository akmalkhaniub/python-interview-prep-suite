# Full Stack Engineer (Marketing Agency) - Interview Prep

This module focuses on the intersection of Full Stack Engineering, AI Automation, and Marketing Technology. The role is centered around building internal tools for a marketing agency, integrating AI into ad workflows, and managing complex attribution data.

## 📁 Module Contents

1.  **[JD Analysis](./jd_analysis.md)**: Deep dive into the requirements, core competencies, and expected interview themes.
2.  **[Technical Study Guide](./study_guide.md)**: Technical breakdowns of Meta CAPI, CRM integrations, AI automation, and Full Stack patterns.
3.  **[Preparation Checklist](./checklist.md)**: A step-by-step 7-day plan to prepare for the interview.

## 🛠️ Key Technologies
- **Frontend:** Next.js, React, Shadcn/UI, Tailwind CSS.
- **Backend:** Python (FastAPI/Flask), Pandas/Polars.
- **MarTech:** Meta Pixel, Conversion API (CAPI), Google Ads API.
- **CRM:** GoHighLevel, Close CRM, HubSpot.
- **AI:** OpenAI API (GPT-4o), LangChain.

## 🎯 Success Metrics for the Role
- Internal tools actively used by media buyers and operators.
- Reduced manual work across campaign and CRM workflows.
- Accurate and reliable tracking and attribution across systems.
- Faster execution of campaigns and reporting.
- AI-driven systems improving lead quality and conversion rates.
