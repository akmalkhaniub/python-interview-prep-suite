# Preparation Checklist: Lead Full Stack Engineer (Trickle Up)

## Phase 1: Technical Foundations
- [ ] **Angular Deep Dive**
    - [ ] Review Change Detection (OnPush).
    - [ ] Practice NgRx/Signals state management.
    - [ ] Implement a complex reactive form with custom validation.
    - [ ] Understand Angular's Dependency Injection system.
- [ ] **Python Mastery**
    - [ ] Implement a microservice with FastAPI and Pydantic.
    - [ ] Code a Circuit Breaker pattern from scratch.
    - [ ] Practice asynchronous programming (`asyncio`).
    - [ ] Write unit and integration tests using `pytest`.

## Phase 2: Architecture & Cloud
- [ ] **System Design**
    - [ ] Design a system for real-time asset tracking in an oil field.
    - [ ] Understand API Gateway patterns and Load Balancing.
    - [ ] Study Database Sharding and Caching strategies (Redis).
- [ ] **Azure & DevOps**
    - [ ] Review Azure DevOps Pipeline YAML syntax.
    - [ ] Understand AKS (Kubernetes) basics: Pods, Services, Deployments.
    - [ ] Practice setting up SLIs/SLOs in a monitoring tool.

## Phase 3: Domain & Leadership
- [ ] **Oil & Gas Domain**
    - [ ] Research common industry KPIs (e.g., NPT - Non-Productive Time).
    - [ ] Understand the basics of SCADA and IoT in energy.
- [ ] **Leadership Scenarios**
    - [ ] Prepare 3 stories about mentoring a junior developer.
    - [ ] Prepare a story about leading a project through a technical crisis.
    - [ ] Practice explaining complex architectural decisions to non-technical stakeholders.

## Phase 4: Final Polish
- [ ] **Mock Interviews**
    - [ ] Conduct a mock system design interview.
    - [ ] Practice behavioral questions using the STAR method.
- [ ] **Portfolio/Code Review**
    - [ ] Ensure personal projects demonstrate clean architecture and testing.
