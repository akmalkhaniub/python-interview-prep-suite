# JavaScript Full-Stack AI Engineer at VentureDive

## About the job
**Location:** Remote (Based in Pakistan, serving global clients)
**Company:** VentureDive (Global technology studio building scalable digital platforms and AI products)

### Role Overview
VentureDive is seeking a talented JavaScript Full-Stack AI Engineer to lead the design, development, and scaling of next-generation AI-powered products. You will work on integrating Large Language Models (LLMs) into production-grade systems, building robust backend APIs, creating fluid user interfaces, and optimizing local inference models.

This role requires a unique balance of modern web engineering (using React and Next.js) and applied AI engineering (including RAG architectures, local model orchestration with Ollama/vLLM, and prompt optimization).

---

### Core Responsibilities
- **End-to-End Development:** Design, write, and deploy full-stack applications with AI models embedded directly into the product workflows.
- **Backend APIs:** Develop secure, low-latency backend services in Node.js, Express, and Python to interface with LLM APIs (OpenAI, Anthropic, etc.).
- **Frontend UIs:** Build responsive, token-streaming interfaces in React and Next.js.
- **Local Model Optimization:** Run, evaluate, and fine-tune open-source LLMs locally (e.g., using Ollama, Llama.cpp, or vLLM) to optimize for API costs and data privacy.
- **AI Orchestration & RAG:** Architect Retrieval-Augmented Generation (RAG) pipelines, construct vector indexes, design system prompt strategies, and implement multi-agent routing.
- **Development Tooling:** Integrate AI-assisted coding tools and automated workflows to accelerate internal development lifecycles.

---

### Must-Have Qualifications
- **Programming Languages:** Proficient in JavaScript/TypeScript and Python.
- **Web Development Frameworks:** Strong expertise in React, Next.js, Node.js, and Express.
- **AI/ML Orchestration:** Hands-on experience with LangChain, LlamaIndex, or equivalent frameworks.
- **Local LLMs:** Practical experience serving and running open-source weights (e.g., Llama 3, Mistral) locally using Ollama or vLLM.
- **Vector Search:** Experience working with vector databases (e.g., Pinecone, ChromaDB, Milvus, Qdrant) and RAG mechanics.
- **API Design:** Experience building and consuming RESTful and WebSocket-based APIs.
- **Cloud & DevOps:** Familiarity with Docker containerization, CI/CD, and deploying applications on AWS or GCP.
