# Model Context Protocol (MCP) Integration Engineer

## About the job
**Location: San Francisco, CA / Remote**

### About the Company
We are a leading developer platform building the next generation of AI development interfaces. Our tools empower millions of developers to write, debug, and scale code with the help of autonomous coding agents. As the capabilities of large language models expand, we believe that standardized protocols are crucial to unlocking their true potential. We are building and extending the **Model Context Protocol (MCP)**, an open-source standard enabling LLMs to interact seamlessly with local and remote files, databases, IDEs, and APIs.

### Role Overview
We are looking for a **Model Context Protocol (MCP) Integration Engineer** to join our Developer Ecosystem & Core Integrations team. In this role, you will design, implement, and maintain high-performance MCP servers and client integrations. You will work at the interface of developer tooling and large language models, defining schemas that make enterprise infrastructure safely accessible to AI models. You will be a key contributor to open-source MCP SDKs (TypeScript, Python, Go) and play a vital role in establishing MCP as the industry standard for tool-use interoperability.

### Key Responsibilities
- **Design and Build MCP Servers:** Implement robust, low-latency MCP servers that expose system tools, database resources, and third-party APIs to LLMs.
- **Maintain Protocol SDKs:** Contribute to core open-source MCP SDKs in Python, TypeScript, and Go, ensuring high performance, proper typing, and clean API design.
- **Client Integrations:** Collaborate with IDE and agent teams to build seamless client-side integrations that parse MCP capabilities, manage user approval prompts, and handle transport channels (STDIO, Server-Sent Events).
- **Security & Authorization Architecture:** Design and enforce fine-grained access control, credential scoping, and execution guardrails to ensure agents can only execute tools safely.
- **Promote Standards & DevRel:** Write developer documentation, cookbooks, and starter templates to accelerate the adoption of MCP among enterprise partners and the open-source community.

### Must-Have Qualifications
- **Software Engineering Foundation:** 4+ years of professional software engineering experience in backend or developer tooling environments.
- **Language Proficiency:** Strong experience in **TypeScript/Node.js** and **Python**.
- **API & Protocol Design:** Proven experience building JSON-RPC, WebSockets, or SSE-based protocols, with a strong focus on schema validation (e.g., JSON Schema, Pydantic).
- **Security Mindset:** Practical understanding of sandboxing (Docker, WASM), secure credential management, and OAuth flows.
- **Developer Focus:** A passion for building high-quality developer tools, CLI utilities, and open-source libraries.

### Nice-to-Have Qualifications
- Familiarity with the internals of LLM tool-calling (function calling) capabilities and agent frameworks.
- Active contributor to open-source developer tooling projects.
- Experience with low-level systems integration or virtual filesystem design.
