# 7-Day Interview Prep Checklist: Full-Stack Engineer (GNO Partners)

## Day 1: Amazon API & Throttling
- [ ] Research **Amazon SP-API** report request flow (create, poll, download).
- [ ] Review **Token Bucket** algorithm and rate-limiting strategies for Node.js.
- [ ] Study **Ads API** campaign management and performance reporting.

## Day 2: Postgres & Supabase Performance
- [ ] Review **Table Partitioning** by `seller_id` (multi-tenancy).
- [ ] Practice writing **Partial Indexes** and **GIN indexes** for JSONB data.
- [ ] Study **Supabase Row-Level Security (RLS)** for data isolation.

## Day 3: AWS Serverless Pipelines
- [ ] Review **AWS Lambda** event-source mappings (SQS, S3).
- [ ] Practice designing a workflow using **AWS Step Functions**.
- [ ] Study **SQS vs. SNS** for decoupled message processing.

## Day 4: Backend: NestJS & Data Transformation
- [ ] Review **NestJS DTOs** and validation for API requests.
- [ ] Practice writing a script to **Transform/Normalize** a raw JSON report into a flat database structure.
- [ ] Study **Idempotency** patterns in serverless functions.

## Day 5: Frontend: React & Data Visualization
- [ ] Review **TanStack Table** (React Table) for handling large datasets.
- [ ] Practice building a simple "Profitability Dashboard" component with **Recharts**.
- [ ] Study **React Performance Optimization** for data-heavy UIs.

## Day 6: AI Insights & Data Structuring
- [ ] Experiment with using LLMs to analyze a **Structured JSON Summary** of sales data.
- [ ] Review **LangChain** basics for tool-calling and agent orchestration.
- [ ] Practice writing a prompt that extracts "Actionable Advice" from Amazon metrics.

## Day 7: Pitch & Product Awareness
- [ ] Finalize your **Data Pipeline success stories**: Problems solved, scale handled.
- [ ] Prepare your "Product-Aware Engineer" pitch: How does data engineering serve the user?
- [ ] Mock interview: Explain the **Trade-offs** of different database indexing strategies for a reporting tool.
