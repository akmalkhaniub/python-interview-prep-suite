# Job Description Analysis: Data Scientist - LineSlip Solutions

## Role Overview
**Company:** LineSlip Solutions (Insurance Mining SaaS)
**Position:** Data Scientist / ML Engineer
**Location:** Fully Remote (Argentina, Pakistan, India encouraged).
**Core Mission:** Automatically extracting and organizing data locked in binders, policies, and insurance documents using LLMs and RAG.

## Core Competencies

### 1. LLM Fine-tuning & Optimization
- **Platforms:** Llama, Falcon, Qwen, OPT, GPT.
- **Techniques:** LoRA, QLoRA, PEFT (Parameter-Efficient Fine-Tuning).
- **Optimization:** Using **Unsloth** for efficient fine-tuning and evaluation.
- **Context:** Handling **Large Context Windows** for long-form insurance policies.

### 2. Retrieval-Augmented Generation (RAG)
- **Vector DBs:** Pinecone, FAISS, Weaviate.
- **Search:** Azure Cognitive Search, Semantic Search.
- **Models:** SentenceTransformers and custom embedding models.

### 3. Agentic AI & Orchestration
- **Frameworks:** **LangChain** and **LangSmith** (Highly preferred).
- **Reasoning:** Building autonomous agents that can query and summarize complex claims data.

### 4. Cloud & MLOps (Azure)
- **Deployment:** Docker, AKS (Azure Kubernetes Service), Azure Machine Learning (AML).
- **Pipelines:** MLflow, Azure Pipelines for CI/CD and retraining.
- **Distributed Training:** DeepSpeed, Ray, or Azure Databricks.

## Key Requirements (The "Filters")
- **Experience:** 4+ years as ML Engineer or Data Scientist.
- **Stability:** 2 years continuous employment with the same employer.
- **Education:** STEM degree completed.
- **Skills:** Expert Python, strong Linux/Shell, highest level of English fluency.

## Key Interview Themes to Prepare

1.  **Fine-tuning at Scale:** How do you decide between LoRA and Full Fine-tuning for an insurance summarization task?
2.  **Long-Document Strategy:** How do you handle a 200-page policy document without losing context or exceeding token limits? (BigBird, Sliding Windows, or Long-context models).
3.  **RAG Optimization:** Discussing chunking strategies, overlap, and reranking to ensure high accuracy in complex data extractions.
4.  **Agentic Workflows with LangSmith:** How do you monitor and debug an agent that needs to navigate multiple insurance documents to find a specific clause?
5.  **Azure MLOps:** Describing a production-grade deployment on AKS using Docker and Azure ML.
6.  **Unsloth Efficiency:** Explaining the memory and speed benefits of using Unsloth for fine-tuning Llama-based models.

## Technical "Must-Haves" for the Interview
- Hands-on experience with **LoRA/QLoRA**.
- Deep knowledge of **LangChain/LangSmith**.
- Proficiency in **Docker** and **AKS**.
- Strong **Linux Shell Scripting** skills.
