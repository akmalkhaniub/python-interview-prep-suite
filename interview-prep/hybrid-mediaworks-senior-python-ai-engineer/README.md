# Hybrid Mediaworks - Senior Python AI/ML Engineer

This module contains preparation materials for the **Senior Python AI/ML Engineer** role at Hybrid Mediaworks. The role is heavily focused on end-to-end Python development, spanning FastAPI/Django backends, LangGraph/RAG AI workflows, Playwright/Scrapy data orchestration, and ML/CV deployments.

## Contents
- `JD.md`: The original job description.
- `cover_letter.md`: A customized cover letter highlighting your full-stack Python capabilities, agentic AI experience, and readiness for the on-site role.
- `interview_questions.md`: Technical Q&A focused on FastAPI async architectures, LangGraph state management, scalable web scraping, and MLOps.
- `7_day_prep_plan.md`: A structured, week-long preparation strategy tailored to the diverse technology stack (Python, Pinecone, YOLO, K8s).
