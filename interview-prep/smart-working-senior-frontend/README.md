# Study Plan: Senior App & Frontend Developer (Smart Working)

This module is tailored for a senior role requiring deep expertise in both **React** and **Angular**, alongside hybrid mobile development with **Ionic/Capacitor** and a focus on **AI-assisted development**.

## 🎯 Role Overview
The role is a mix of high-level architecture and hands-on execution. You are expected to be the "Frontend Lead" in a small team, making decisions on:
1.  **Framework Selection & Migration:** Handling both React (10+ years depth) and Angular 15+.
2.  **Hybrid Mobile Strategy:** Using Ionic 7 and Capacitor to bridge web and native.
3.  **Efficiency:** Integrating AI tools (Copilot, Cursor, ChatGPT, custom LLM agents) into the dev loop.

## 🛠️ Tech Stack Focus
*   **React:** Advanced patterns (Server Components, Hook optimization, State Management).
*   **Angular 15+:** Signals, Standalone Components, Functional Interceptors.
*   **Ionic 7 / Capacitor:** Native plugins, bridge performance, mobile-first CSS.
*   **AI Dev Tools:** Prompt engineering for code generation, automated unit testing.
