## Role Focus
- **Tech Stack:** Python (Django), TypeScript (React/React Native), AWS (Lambda, DynamoDB, SQS).
- **Domain:** Sustainability (reducing waste, supply chain efficiency).
- **Level:** Senior leadership with a focus on team velocity and high-autonomy delivery.

## Quick Tips
- Emphasize your **serverless experience** and ability to design cloud-native systems.
- Be prepared to discuss **cross-platform mobile** development using React Native.
- Highlight your **leadership** skills in improving team processes and code quality.
