# Job Description Analysis: Senior Full Stack Engineer - Ciklum

## Role Overview
**Company:** Ciklum (Custom Product Engineering Company)
**Position:** Senior Full Stack Engineer
**Location:** Pakistan (Islamabad / Hybrid)
**Domain:** Sustainability Tech (Supply chain efficiency, waste reduction).
**Autonomy:** High; working in an entrepreneurial tech team.
**Stack:** Python, Django, Typescript, React, React Native, AWS Serverless.

## Core Competencies

### 1. Full-Stack Mastery (Python & JS)
- **Backend:** Python and Django.
- **Frontend/Mobile:** TypeScript, React, and React Native (Cross-platform experience).
- **Flexibility:** Open to different languages/frameworks, but current focus is the above.

### 2. AWS Serverless & Cloud Infrastructure
- **Services:** Lambda, S3, DynamoDB, API Gateway, SNS/SQS.
- **Infrastructure:** AWS Cloud infrastructure and CI/CD (GitHub Actions).
- **Architecture:** Familiarity with modern software architecture and cloud design patterns.

### 3. Engineering Leadership & Quality
- **Ownership:** Leading delivery of complex projects and technical designs.
- **Velocity:** Increasing team efficiency through engineering best practices.
- **Quality:** Ownership of code quality via testing, code reviews, and documentation.
- **Communication:** Explaining technical concepts to all audiences (stakeholder engagement).

## Key Requirements
- **Experience:** Extensive experience in commercial environments (6+ years implied by "Senior").
- **Autonomy:** Comfortable in high-autonomy, collaborative environments.
- **Problem Solving:** Excellent technical debugging and complex issue mitigation skills.

## Interview Themes to Prepare
1.  **Serverless Architecture:** Designing event-driven systems using AWS Lambda, SQS, and SNS.
2.  **Django Scalability:** Optimizing Django for performance and integrating it with serverless AWS components.
3.  **Cross-Platform React:** Strategies for sharing code between React (web) and React Native (mobile).
4.  **Sustainability Domain:** Thinking about supply chain data, waste reduction metrics, and resource efficiency.
5.  **Team Velocity:** How to implement "Best Practices" (CI/CD, automated testing) to speed up a scaling team.
6.  **Cloud Design Patterns:** Discussing Circuit Breakers, Retry logic, and Idempotency in a serverless context.
