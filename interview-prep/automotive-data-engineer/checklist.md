# 7-Day Interview Prep Checklist: Automotive Data Engineer

## Day 1: Automotive Domain & Messy Data
- [ ] Review **VIN structure** and decoding (Year, Make, Model, Trim, Engine).
- [ ] Study common **Automotive Taxonomies** and inconsistent data patterns.
- [ ] Practice writing **Regex** for VIN and part number extraction.

## Day 2: Data Cleaning & Normalization
- [ ] Review **Fuzzy Matching** algorithms (Levenshtein, Jaro-Winkler).
- [ ] Practice building a **Normalization script** in Python for automotive colors or features.
- [ ] Study **Deduplication strategies** (Blocking and Scoring).

## Day 3: Pipelines & Orchestration
- [ ] Review **Airflow** or **Prefect** DAG patterns for incremental loading.
- [ ] Practice designing a **Scalable Ingestion Pipeline** using Redis and Python workers.
- [ ] Study **API Design** for syncing fresh data across distributed systems.

## Day 4: Searching & Indexing (Elasticsearch)
- [ ] Review **Elasticsearch Mappings** for faceted automotive search.
- [ ] Practice writing **Elasticsearch Aggregations** for inventory pricing trends.
- [ ] Study **Geo-search** and **Boosting** logic in Elasticsearch.

## Day 5: AI-Assisted Data Extraction
- [ ] Review **Prompt Engineering** for extracting features from dealer descriptions.
- [ ] Practice using **Pydantic** to validate and structure AI-extracted data.
- [ ] Research **Agentic workflows** for autonomous data collection and self-healing scrapers.

## Day 6: Monitoring & Reliability
- [ ] Study **Data Observability** metrics (Completeness, Correctness, Freshness).
- [ ] Practice setting up **Monitoring/Alerting** for a Python pipeline.
- [ ] Review **Error-handling** and **Dead Letter Queues** for failed ingestion tasks.

## Day 7: Pitch & Domain Deep-Dive
- [ ] Finalize your "Automotive Experience" stories: Complex cleaning, large-scale migrations, or AI integration.
- [ ] Review the **Trade-offs** between Accuracy, Speed, and Cost for high-volume pipelines.
- [ ] Mock interview: Explain your process for "Entity Resolution" to a non-technical stakeholder.
