# Job Description Analysis: Data Science & Analytics - TikTok Shop

## Role Overview
**Company:** TikTok Shop (International E-commerce)
**Position:** Data Scientist (C-end Focus)
**Location:** Singapore / Global focus.
**Focus:** User Growth, Traffic Conversion, User Experience Optimization, Risk Control.
**Level:** 3+ years experience.

## Core Competencies

### 1. User Behavior & Growth Analytics
- **C-end Focus:** Concentrating on traffic conversion, engagement, and retention.
- **Conversion Optimization:** Mining user behavior data to improve ROI of user benefits and conversion rates.
- **A/B Testing:** Design and analysis of experiments to optimize product features and user experience.

### 2. Technical Modeling & Mining
- **Techniques:** Advanced statistics, machine learning, and deep learning.
- **Tools:** Proficient in SQL; skilled in Python/R for modeling.
- **Big Data:** Familiarity with Hadoop, Spark, and Hive (Hadoop ecosystem).

### 3. Risk Control & Platform Safety
- **Rule Development:** Identifying and preventing abnormal behaviors (fraud, abuse).
- **Strategy:** Designing rules to ensure platform safety while supporting growth.

### 4. Business Acumen & Collaboration
- **Cross-functional:** Partnering with Product, Operations, and Engineering.
- **Decision Support:** Translating data into actionable business insights for continuous iteration.

## Key Requirements
- **Experience:** 3+ years in user data analysis, growth, or risk control.
- **Industry Knowledge:** Global e-commerce or content commerce (TikTok's unique model) experience is preferred.
- **Mindset:** "Always Day 1" mindset—resilient, curious, and impact-driven.

## Interview Themes to Prepare
1.  **A/B Testing Deep Dive:** How to design an experiment for a new "Live E-commerce" feature and handle interference between control and treatment groups (Network Effects).
2.  **Conversion Funnel Analysis:** Identifying bottlenecks in the TikTok Shop user journey from "Video/Live discovery" -> "Product Detail" -> "Checkout."
3.  **ROI Optimization:** How to calculate and optimize the ROI of user subsidies or discount coupons.
4.  **Risk Modeling:** Designing a model to detect "Scalper" behavior or fake transactions in a flash sale scenario.
5.  **Data Strategy for E-commerce:** How to use short-video engagement metrics to predict purchase intent.
6.  **Big Data Scalability:** Discussing how to handle and process terabytes of user clickstream data using Spark/Hive.
