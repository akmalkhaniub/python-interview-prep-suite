# Senior Backend Engineer (Proxy & Unblocking) - Apify

## About the job
**Location: Prague, Czechia / Hybrid (Remote Friendly)**

### Role Description
Web scraping is a constant cat-and-mouse game against web application firewalls and bot-detection engines. As a Senior Backend Engineer for Proxy and Unblocking, you will own the core infrastructure that enables millions of web automation actors to retrieve clean data under adversarial conditions. 

You will lead the research into anti-scraping systems, implement stealth request fingerprinting techniques, and optimize our proxy distribution systems for maximum availability and reliability.

### Key Responsibilities
- **Proxy Infrastructure Engineering:** Expand and scale Apify Proxy, integrating new upstream proxy providers and optimizing IP-rotation algorithms.
- **Unblocking Research:** Actively reverse engineer anti-bot systems (like Cloudflare, DataDome, and Akamai) to understand their detection signals (TLS handshakes, browser metrics, TCP profiles).
- **Stealth Automation:** Implement fingerprint-spoofing systems, human-like interaction models, and session persistence strategies to bypass behavioral detectors.
- **Open-Source Contributions:** Maintain and contribute to Apify's open-source packages, such as `proxy-chain` (a Node.js proxy server implementation) and `impit` (TLS-spoofing components).

### Requirements
- **Experience:** 2+ years of software engineering experience specifically building proxy services, unblocking APIs, or browser fingerprint spoofing solutions.
- **Technical Stack:** Strong proficiency in developing and debugging with **TypeScript / Node.js** (or equivalent experience in another language with the ability to learn quickly).
- **Protocols & Systems:** High familiarity with Linux environments, Docker container scaling, and cloud platforms (AWS).
- **Deep Network Understanding:** Excellent knowledge of HTTP/1.1, HTTP/2, WebSockets, TLS Client Hello parameters, and TCP/IP routing.
- **Experimentation Mindset:** A data-driven, iterative debugging approach to find bypasses against constantly changing security systems.
