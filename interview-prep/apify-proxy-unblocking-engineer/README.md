# Apify - Senior Backend Engineer (Proxy & Unblocking) Prep

This module contains preparation materials for the **Senior Backend Engineer (Proxy & Unblocking)** role at Apify. The curriculum focuses on proxy protocol internals, load balancing, reverse proxying, TLS fingerprint bypasses, HTTP/2 frame headers, and browser fingerprint analysis.

- [JD.md](file:///g:/ReplitProjects/telemedicine/python-engineer-notebooks/interview-prep/apify-proxy-unblocking-engineer/JD.md): The job description and core requirements.

- [02-unblocking-reverse-engineering.md](file:///g:/ReplitProjects/telemedicine/python-engineer-notebooks/interview-prep/apify-proxy-unblocking-engineer/02-unblocking-reverse-engineering.md): Bypassing HTTP/2 and TLS fingerprints (JA3/JA4, HTTP/2 settings, window sizes), TCP/IP OS fingerprinting (p0f), and reverse engineering Javascript anti-bot challenges (Akamai, Cloudflare).
