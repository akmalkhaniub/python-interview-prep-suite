# Full-Stack AI Engineer (Intelligent Automation & GenAI) at Deloitte Luxembourg

## About the job
**Location:** Luxembourg City, Luxembourg (Onsite / Hybrid)
**Company:** Deloitte Luxembourg (Leading professional services firm delivering strategic consulting, risk advisory, and intelligent automation solutions)

### Role Overview
We are seeking a Full-Stack AI Engineer to design, build, and deploy enterprise-grade GenAI and intelligent automation solutions for our clients in the financial services, public sector, and asset management industries. 

In this role, you will bridge the gap between AI research and practical enterprise software. You will develop backend services (Python and Java/Spring Boot) to interface with Azure OpenAI, construct frontend user portals (React), deploy secure document search frameworks (RAG), and ensure all solutions comply with European regulations (specifically the EU AI Act and GDPR).

---

### Core Responsibilities
- **Enterprise Solution Delivery:** Own the end-to-end development of AI-powered applications, from backend services and database structures to frontend user interfaces.
- **Model Integration:** Connect, orchestrate, and optimize Large Language Models (LLMs) using Azure OpenAI Service, LangChain, and semantic search.
- **Hybrid Backend Systems:** Implement microservices using a hybrid of Python (for NLP, LLM calls, and data parsing) and Java / Spring Boot (for enterprise security and core business logic).
- **Frontend Portals:** Build intuitive, responsive dashboards in React to allow users to interact with AI models and visualize document extraction results.
- **European Regulatory Compliance:** Ensure all AI architectures strictly conform to GDPR data privacy requirements, auditability standards, and the EU AI Act classification rules.
- **Production MLOps:** Package and deploy applications using Docker and Kubernetes, ensuring scalability, security, and continuous integration.

---

### Must-Have Technical Stack & Qualifications
- **Education:** Master’s or PhD degree in Computer Science, Data Science, Artificial Intelligence, or a related quantitative field.
- **Programming Languages:** Proficiency in Python and Java.
- **Frontend Stack:** Experience building modern web applications using React.
- **AI Stack:** Hands-on experience with LLM orchestration (LangChain), vector search databases (Pinecone, ChromaDB, PGVector), and deep learning frameworks (PyTorch or TensorFlow).
- **Enterprise Frameworks:** Solid experience with Spring Boot for enterprise backend services.
- **DevOps:** Experience with Docker, Kubernetes, and CI/CD pipelines.
- **Languages:** Fluent in English (written and spoken). Proficiency in French is a strong advantage.
- **Regulatory Awareness:** Familiarity with European data privacy laws (GDPR) and the EU AI Act framework.
