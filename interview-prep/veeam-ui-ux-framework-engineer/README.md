## Role Focus
- **Tech Stack:** Vue.js, JavaScript (Async), Webpack, Jenkins.
- **Key Task:** Building software components and tools for data analytics and enterprise problems.
- **Responsibility:** Ownership from design to production launch.

## Quick Tips
- Focus on your experience with **high-performance** UI (rendering large datasets, smooth interactions).
- Be ready to discuss **API contract design** and how you collaborate with platform teams.
- Highlight your passion for **code quality** and **security**, which are critical in the data resilience space.
