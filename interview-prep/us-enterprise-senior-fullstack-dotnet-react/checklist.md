# 7-Day Interview Prep Checklist: Senior Full Stack Developer (US Enterprise)

## Day 1: .NET & C# Mastery
- [ ] Review ASP.NET Core 8 core concepts (DI, Middleware, Routing).
- [ ] Practice building a complex C# API with EF Core.
- [ ] Study advanced C# features (Pattern matching, Async).

## Day 2: React & TypeScript Frontend
- [ ] Review React hooks and advanced state management.
- [ ] Practice building a pixel-accurate UI from a mockup.
- [ ] Study TypeScript advanced types and Vite configuration.

## Day 3: SQL Server & Performance
- [ ] Review Execution Plans and Index optimization.
- [ ] Practice writing complex window functions and CTEs.
- [ ] Study SQL Server schema design for large enterprise datasets.

## Day 4: AI & LLM Integrations
- [ ] Practice integrating OpenAI or Gemini APIs in a .NET application.
- [ ] Research RAG architecture and prompt engineering best practices.
- [ ] Study Semantic Kernel or Azure OpenAI SDK.

## Day 5: Cloud & Architecture
- [ ] Review GCP (Cloud Run, Cloud SQL) or Azure services.
- [ ] Study Microservices and Cloud-native design patterns.
- [ ] Research CI/CD pipeline automation (GitHub Actions/Azure DevOps).

## Day 6: Testing & Mentorship
- [ ] Practice writing xUnit/Jest tests for a full-stack feature.
- [ ] Prepare "Mentorship" stories: Guiding junior developers, code review feedback.
- [ ] Review Agile/Scrum processes and best practices.

## Day 7: Mock Interview & Soft Skills
- [ ] Conduct a mock "System Design" interview: "Design an AI-powered enterprise analytics dashboard."
- [ ] Prepare "Behavioral" stories: Handling ambiguity, solving complex bugs.
- [ ] Final review of English communication and technical explanation skills.
