## Role Focus
- **Stack:** TS/Next.js + Python/FastAPI + AWS.
- **Innovation:** The model is part of the runtime; agents drive real execution and code changes.
- **Sandboxing:** Deep use of E2B and Docker for secure, isolated code execution.
- **Mindset:** Extreme ownership, bias to ship, and ability to debug stochastic systems.

## Quick Tips
- Focus on your **execution-driven AI** experience (not just chat).
- Be prepared to discuss **sandboxing and security** for untrusted code.
- Highlight your ability to manage **multi-provider AI quirks** and real-time UI streaming (SSE).
