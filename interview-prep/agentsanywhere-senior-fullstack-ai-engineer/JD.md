About the job
Senior Full-Stack AI Engineer

Agentsanywhere is building a multi-agent platform where LLMs plan, investigate, execute, and ship real software end-to-end across cloud sandboxes, real customer workflows, and live integrations. The model is part of the runtime, not a feature you bolt on.

The stack you'll own end-to-end:

TypeScript / Next.js (App Router): Prisma + PostgreSQL, NextAuth, Tailwind, Vercel AI SDK, tRPC, SSE streaming
Python / FastAPI: async services, vector DBs, RAG pipelines, document parsing (PDF/DOCX), embedding workflows
AI agent systems: multi-step tool-use loops, multi-provider (Anthropic, OpenAI, Google), prompt + context engineering, memory + compaction, streaming + tool-call quirks across vendors
Cloud sandboxes: E2B, Docker, container lifecycle, file/process supervision, snapshot/restore
AWS: Deployment, scaling, monitoring
Real-time: SSE, WebSockets, background workers, fan-out to live UIs
Integrations: OAuth, webhooks, Composio-style brokers, Stripe, GitHub, Slack

You should have:

5+ years shipping production systems at scale, multi-tenant, real traffic, real users
Built systems where model output drives execution, not just chat UIs
Designed schemas that evolve weekly without breaking what's deployed
Debugged stochastic systems, drift, hallucinations, infinite loops, partial failures
Shipped end-to-end on AWS without hand-holding
Worked on bigger products where reliability, cost, and latency all mattered
Strong bias to ship. Comfortable in ambiguity. Strong opinions, light hold.
