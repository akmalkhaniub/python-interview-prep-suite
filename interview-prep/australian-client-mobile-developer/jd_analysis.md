# Job Description Analysis: Mobile Front-End Developer (Australian Client)

## Role Overview
**Client Region:** Australia (AEST Hours)
**Position:** Mobile Front-End Developer (Flutter / React Native)
**Experience:** 7-10 years.
**Core Stack:** Flutter + Flutter Web, BLoC State Management, React Native (Expo).
**Mandatory Focus:** Flutter Web and BLoC (Business Logic Component).

## Core Competencies

### 1. Flutter Mastery
- **State Management:** Deep expertise in **BLoC** (mandatory).
- **Multi-platform:** Experience with both Mobile and **Flutter Web**.
- **UI/UX:** Building high-performance, responsive interfaces.

### 2. React Native & Expo
- **Expo Ecosystem:** Managing projects within the Expo managed or bare workflow.
- **Cross-platform:** Shared logic between React Native and Flutter projects if required.

### 3. API & Data
- **REST APIs:** Solid integration skills.
- **GraphQL:** Familiarity (plus).
- **State Persistence:** Handling local storage and offline capabilities.

### 4. Software Engineering Excellence
- **Testing:** Unit, Widget, and Integration tests.
- **Optimization:** Debugging performance bottlenecks and memory leaks.
- **Process:** Agile/Scrum, Git, and collaborative code reviews.

## Key Interview Themes to Prepare

1.  **BLoC in Depth:** Explain streams, sinks, and why BLoC is superior for scalable Flutter apps compared to Provider or Riverpod (in the context of this role).
2.  **Flutter Web Nuances:** Discussing the differences in rendering (CanvasKit vs. HTML), SEO challenges, and responsive design for web.
3.  **Expo vs. CLI:** When to use Expo and how to handle native modules when they are not supported in the managed workflow.
4.  **AEST Collaboration:** Handling remote work and overlapping hours with an Australian team.
5.  **Clean Architecture:** How to structure a Flutter project for 7-10 years of scalability (Data, Domain, and Presentation layers).
6.  **Performance Profiling:** Using DevTools for Flutter and Flipper/Performance Monitor for React Native.

## Technical "Must-Haves" for the Interview
- A solid project example using **BLoC** state management.
- Experience deploying to both iOS/Android and **Web** using Flutter.
- Strong understanding of **Dart Streams** and **Async/Await** patterns.
