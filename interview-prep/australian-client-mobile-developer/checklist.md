# 7-Day Interview Prep Checklist: Mobile Front-End Developer (Flutter/RN)

## Day 1: Flutter BLoC Fundamentals
- [ ] Review `flutter_bloc` documentation.
- [ ] Practice building a "Counter" or "Todo" app using pure BLoC (not Cubit).
- [ ] Study `BlocObserver` for global state logging.

## Day 2: Advanced BLoC & Architecture
- [ ] Implement **Clean Architecture** layers (Data, Domain, Presentation).
- [ ] Practice BLoC-to-BLoC communication.
- [ ] Review BLoC `transformers` for event concurrency.

## Day 3: Flutter Web & Responsiveness
- [ ] Build a simple dashboard that works on both Mobile and Web.
- [ ] Experiment with `LayoutBuilder` and `responsive_framework`.
- [ ] Research CanvasKit vs. HTML rendering trade-offs.

## Day 4: React Native & Expo
- [ ] Review **Expo SDK** latest features (Expo Router, EAS).
- [ ] Compare **Zustand** or **Redux** with BLoC patterns.
- [ ] Practice setting up an Expo project with TypeScript.

## Day 5: APIs, GraphQL & Performance
- [ ] Review `Dio` interceptors for auth and logging.
- [ ] Study **GraphQL** basics (Queries, Mutations) in a Flutter/RN context.
- [ ] Profile a Flutter app using **DevTools** (Performance/Memory).

## Day 6: Testing & Quality Assurance
- [ ] Write unit tests for a BLoC using `bloc_test`.
- [ ] Practice **Widget Testing** in Flutter.
- [ ] Review Git best practices and Agile/Scrum ceremony details.

## Day 7: Strategic & Cultural Alignment
- [ ] Formulate answers for "Why BLoC?" and "Mobile-First vs. Responsive."
- [ ] Prepare for **AEST time-zone** discussion (Working 10am-6pm AEST).
- [ ] Final review of the "Clean Architecture" and "State Management" deep-dives.
