# 7-Day Interview Prep Checklist: React Native Lead (Tether)

## Day 1: Advanced React Native & Redux
- [ ] Review the **New Architecture** (JSI, Fabric, TurboModules).
- [ ] Practice complex **Redux Toolkit** patterns (Slices, Middleware, RTK Query).
- [ ] Research **MMKV** vs. **AsyncStorage** for high-speed local persistence.

## Day 2: Native Bridging & C++
- [ ] Practice writing a simple **JSI Module** in C++.
- [ ] Review **Swift** and **Kotlin** syntax for basic Native Module implementation.
- [ ] Understand the thread model of React Native (JS thread, UI thread, Background thread).

## Day 3: Crypto & Blockchain Mastery
- [ ] Study **BIP-39**, **BIP-44**, and **BIP-32** standards.
- [ ] Understand how to sign an Ethereum or Bitcoin transaction in JS vs. Native code.
- [ ] Review **Secure Enclave** (iOS) and **Keystore** (Android) security principles.

## Day 4: Full-Stack Integration (Node.js)
- [ ] Practice building a **BFF (Backend-for-Frontend)** using Express/Node.js.
- [ ] Study **WebSocket** patterns (Reconnection, Heartbeat, State Sync).
- [ ] Review **JWT** and **Biometric Auth** integration.

## Day 5: CI/CD & Deployment
- [ ] Review **Expo EAS** (Build, Submit, Update).
- [ ] Study **Mobile E2E Testing** with Detox or Maestro.
- [ ] Research **SSL Pinning** and **Code Obfuscation** techniques.

## Day 6: Leadership & System Design
- [ ] Formulate stories for **Mentorship**, **Conflict Resolution**, and **Technical Ownership**.
- [ ] Design a **High-Performance Wallet Architecture** on paper.
- [ ] Prepare your "Full-Stack" pitch: How you unblock mobile delivery by contributing to the backend.

## Day 7: Strategic Review & Mock Interviews
- [ ] Final review of the "Crypto" and "Native" deep-dives.
- [ ] Research **Tether's transparency reports** and latest product launches (USDT on new chains).
- [ ] Prepare questions for the interviewers (Engineering culture, technical debt, roadmap).
