# Job Description Analysis: React Native Lead - Tether

## Role Overview
**Company:** Tether (Stablecoin Leader)
**Position:** React Native Lead / Senior Mobile Engineer
**Core Mission:** Building high-performance crypto wallet solutions and DeFi features within a remote, global team.
**Key Differentiator:** Requires "Native Modules (C++)" and "Full-Stack (Node.js)" capabilities alongside senior React Native leadership.

## Core Competencies

### 1. React Native & Expo Ecosystem
- **Expertise:** React, React-Native, Redux.
- **Tools:** Expo (primary), CI/CD pipelines.
- **Architecture:** Owning patterns for state, navigation, and security.

### 2. Low-Level & Native Integration
- **C++ Modules:** High performance/low-level implementation for crypto logic.
- **Native Languages:** Swift/Objective-C (iOS) and Kotlin/Java (Android).
- **Real-time:** WebSockets for live market data and wallet updates.

### 3. Full-Stack & Integration
- **Backend:** Node.js (Ability to implement/adjust APIs to unblock mobile delivery).
- **SDKs:** Integrating JavaScript SDKs for blockchain and DeFi.
- **End-to-End:** Ownership of features across the entire stack.

### 4. Leadership & Mentorship
- **Management:** Leading a small group of engineers.
- **Standards:** Driving architectural decisions and enforcing coding standards.
- **Delivery:** Ensuring timely, high-quality delivery.

## Key Interview Themes to Prepare

1.  **Crypto Wallet Architecture:** Designing secure, light-weight wallet interfaces (mnemonic handling, transaction signing logic).
2.  **C++ in React Native:** Why and how to use C++ (JSI) for performance-critical crypto operations.
3.  **Cross-Stack Fluidity:** Discussing scenarios where you modified a Node.js backend to support a new mobile feature.
4.  **Security & DeFi:** Handling private keys, Seed Phrases (BIP-39), and Web3 integrations securely in React Native.
5.  **State Management (Redux):** Advanced Redux patterns for complex, real-time wallet states.
6.  **CI/CD for Global Teams:** Managing deployments for a distributed team at Tether's scale.

## Technical "Must-Haves" for the Interview
- Deep knowledge of the **React Native Bridge vs. JSI**.
- Experience with **WebSockets** for real-time crypto price feeds.
- Proven track record of **Leading** a team of engineers.
- Knowledge of **BIP-44** (Hierarchical Deterministic Wallets) is highly recommended.
