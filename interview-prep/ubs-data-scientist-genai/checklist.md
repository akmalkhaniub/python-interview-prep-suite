# Interview Prep Checklist: Data Scientist (UBS)

## Phase 1: Core GenAI & RAG (Days 1-2)
- [ ] **Master RAG Architectures:** Review advanced retrieval techniques (Hybrid search, Re-ranking).
- [ ] **Evaluate LLMs:** Learn how to use the RAGAS framework or similar to quantify model quality.
- [ ] **Prompt Engineering:** Practice Few-shot, Chain-of-Thought, and Self-consistency prompting.

## Phase 2: Agentic AI & Tooling (Days 3-4)
- [ ] **Explore LangGraph/CrewAI:** Understand how to build multi-agent systems with state management.
- [ ] **API Integration:** Review how to define "Tools" for LLMs (JSON schemas for function calling).
- [ ] **Vector DB Deep Dive:** Compare indexing methods (HNSW vs IVFFlat) and their trade-offs.

## Phase 3: Financial Domain & MLOps (Days 5-6)
- [ ] **Compliance & Governance:** Read about MAS (Singapore) FEAT principles for AI in finance.
- [ ] **Responsible AI:** Review techniques for data anonymization and hallucination detection.
- [ ] **MLOps Pipeline:** Design a conceptual pipeline from data ingestion to model monitoring in a regulated cloud environment (Azure/AWS).

## Phase 4: Mock Interviews & Polish (Day 7)
- [ ] **STAR Stories:** Prepare 3-4 stories focusing on technical leadership and business impact.
- [ ] **Financial Case Study:** Practice explaining a complex ML solution to a non-technical stakeholder (e.g., a Wealth Manager).
- [ ] **Review UBS Values:** Alignment with collaboration and "innovation within boundaries."

---
**Key Concepts to Review:**
- **FEAT Principles:** Fairness, Ethics, Accountability, and Transparency.
- **RAGAS Metrics:** Faithfulness, Answer Relevance, Context Recall.
- **Hugging Face Ecosystem:** PEFT, LoRA, Accelerate.
