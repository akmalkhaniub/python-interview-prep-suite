# Data Scientist (GenAI & ML) - UBS Global Wealth Management

This module is designed for the Data Scientist position at UBS Singapore, focusing on delivering advanced AI solutions within a highly regulated financial environment. The role emphasizes GenAI (RAG, Agents), MLOps, and responsible AI.

## 📁 Module Contents

1.  **[JD Analysis](./jd_analysis.md)**: Analysis of role expectations, core competencies (GenAI/MLOps), and interview themes.
2.  **[Technical Study Guide](./study_guide.md)**: Deep dives into RAG architectures, Agentic AI, MLOps in finance, and evaluation frameworks.
3.  **[Preparation Checklist](./checklist.md)**: A 7-day preparation roadmap tailored for the Singapore financial sector.

## 🛠️ Key Technologies
- **GenAI:** RAG, Prompt Engineering, Agentic AI (LangChain, LangGraph).
- **ML Frameworks:** PyTorch, TensorFlow, Scikit-learn, Hugging Face.
- **Data/Infrastructure:** Vector Databases (Pinecone/Milvus), Docker, CI/CD.
- **Compliance:** Responsible AI, Model Validation, Data Privacy (PII).

## 🌍 Strategic Focus: Wealth Management
- Developing intelligent tools for financial advisors.
- Building reusable AI components for global operations.
- Navigating Singapore's financial regulations (MAS guidelines).
