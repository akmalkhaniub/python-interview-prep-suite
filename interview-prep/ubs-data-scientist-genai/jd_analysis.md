# Job Description Analysis: Data Scientist (GenAI & ML) - UBS

## Role Overview
**Company:** UBS (Global Wealth Management)
**Position:** Data Scientist
**Location:** Singapore (Full Time)
**Focus:** GenAI, Agentic AI, RAG, MLOps, Wealth Management Solutions.
**Level:** 5+ years experience + Master's/PhD.

## Core Competencies

### 1. Generative AI & NLP
- **Techniques:** Retrieval-Augmented Generation (RAG), Prompt Engineering, Fine-tuning LLMs.
- **Frameworks:** LangChain, Hugging Face, Agentic workflows.
- **Applications:** Reasoning agents, intelligent tools for advisors and clients.

### 2. Machine Learning & Engineering
- **Modelling:** Developing, testing, and deploying ML models for business use cases.
- **Tools:** Python, PyTorch, TensorFlow, Scikit-learn.
- **Integration:** Integrating AI capabilities into existing scalable systems via APIs.

### 3. Data & MLOps
- **Pipelines:** Building pipelines for data prep, experimentation, and monitoring.
- **Tools:** CI/CD, Model Registry, Vector Databases, Containerization (Docker).
- **Quality:** Evaluation frameworks and feedback loops for model performance.

### 4. Responsible AI & Compliance
- **Governance:** Working within regulated industries (Wealth Management).
- **Safety:** Transparency, compliance, and data privacy considerations.
- **Validation:** Model validation best practices.

## Key Requirements
- **Education:** Master’s or PhD in CS, ML, or Data Science.
- **Experience:** 5+ years in enterprise/research environments.
- **Industry Knowledge:** Financial services / regulated industry experience is a significant asset.

## Interview Themes to Prepare
1.  **RAG Architecture:** Designing a secure RAG system for wealth managers to query internal research reports while maintaining data privacy.
2.  **Agentic AI:** Implementing a "Reasoning Agent" that can orchestrate multiple tools (e.g., portfolio analysis API + market data) to answer a client query.
3.  **MLOps in Banking:** How to implement a robust model monitoring and validation pipeline in a highly regulated environment.
4.  **Model Evaluation:** Designing an evaluation framework for LLM outputs (e.g., using G-Eval, RAGAS, or human-in-the-loop) to ensure accuracy in financial advice.
5.  **Data Privacy:** Handling PII (Personally Identifiable Information) in prompt engineering and vector database storage.
