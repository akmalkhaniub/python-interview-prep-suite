# 7-Day Interview Prep Checklist: AI Orchestrator (Novo AI)

## Day 1: The "No-Code" Architect Mindset
- [ ] Practice **Architectural Sketching**: Design a complex system (e.g., an automated medical bill auditor) without writing a single line of code.
- [ ] Review **Claude & Cursor** best practices: Using "Composer" and high-level specs to build features.
- [ ] Study **Spec-Driven Development**: How to write high-fidelity Markdown specs for AI.

## Day 2: Agentic Frameworks (LangGraph & AutoGen)
- [ ] Review **LangGraph** for building cyclic, stateful multi-agent workflows.
- [ ] Study **AutoGen** for multi-agent conversations and collaborative problem solving.
- [ ] Practice building a simple **Orchestrator-Worker** loop in Python (orchestrated by AI).

## Day 3: Document Intelligence & Extraction
- [ ] Review **LLM-as-a-Judge** patterns for validating structured data.
- [ ] Study common **Medical Document Formats** (ICD-10 codes, hospital invoice line items).
- [ ] Practice building an **Extraction Prompt** that handles messy, inconsistent JSON fields.

## Day 4: Production Autonomy & Watchdogs
- [ ] Review **Self-Correction Patterns**: How agents can detect and fix their own execution errors.
- [ ] Practice building a **"Problem Statement Generator"** that turns a Python traceback into a business-level RCA.
- [ ] Study **Guardrails** for autonomous agents (e.g., input/output filtering).

## Day 5: BI & SQL Hypothesis Formation
- [ ] Review **SQL-Agent** architectures: Connecting agents to read-only database tools.
- [ ] Practice **Chain-of-Thought (CoT)** prompting for data analysis tasks.
- [ ] Research **Medical Inflation Trends** and common **Insurance Fraud patterns**.

## Day 6: Systems Thinking (Google Style)
- [ ] Study **Decoupling & Resilience** in distributed AI systems.
- [ ] Practice **High-Level System Design**: How would you scale an agent pipeline to 10,000 documents per hour?
- [ ] Prepare your "Output-driven" stories: Successes in high-leverage AI orchestration.

## Day 7: Pitch & Elite Vision
- [ ] Finalize your **"AI Orchestrator"** pitch: Why syntax is dead and architecture is everything.
- [ ] Review **Novo AI's mission** and their impact in Singapore, Thailand, and France.
- [ ] Mock interview: Architect a **Self-Improving Agent Pipeline** for a complex insurance scenario in real-time.
