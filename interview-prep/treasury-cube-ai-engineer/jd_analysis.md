# Job Description Analysis: AI Engineer - Treasury Cube

## Role Overview
**Company:** Treasury Cube
**Position:** AI Engineer (Lead Role)
**Mission:** Transforming corporate treasury (cash, payments, bank connectivity) using deeply embedded AI insights and automation.
**Target Users:** CFOs and Corporate Treasurers.
**Stack:** Azure-centric (OpenAI, Foundry, Search, Document Intelligence).

## Core Competencies

### 1. Azure AI Ecosystem
- **Azure OpenAI Service:** Orchestration and model management.
- **Azure AI Search:** Vector + hybrid retrieval for RAG.
- **Azure AI Foundry:** For building and scaling AI applications.
- **Azure AI Document Intelligence:** Parsing bank statements and financial docs.
- **Azure Content Safety:** Ensuring financial data handling meets safety standards.

### 2. RAG & Agentic Workflows
- **Retrieval:** Advanced RAG over complex treasury data.
- **Orchestration:** Multi-step automation using Azure Functions, Logic Apps, and Durable Functions.
- **Tooling:** Familiarity with Semantic Kernel, LangChain, or LlamaIndex.

### 3. Backend & FinTech Fundamentals
- **Languages:** Python and/or C#/.NET.
- **Integrations:** ISO 20022 (CAMT, PAIN), SWIFT, banking APIs.
- **Architecture:** Multi-tenant SaaS, data isolation, REST APIs.

### 4. Production AI (LLMOps)
- **Observability:** Token usage, latency, hallucination detection.
- **Evaluation:** Prompt regression testing, human-in-the-loop pipelines.
- **Cost Management:** Cost-per-customer tracking.

## Key Projects/Deliverables
1.  **AI Insights Engine:** Explanatory commentary on cash positions and FX exposure.
2.  **Conversational Assistant:** Natural language interface for treasury data queries.
3.  **Task Automation:** Intelligent routing of alerts (covenant breaches, payment exceptions).

## Interview Themes to Prepare
1.  **Grounded Financial Answers:** How to ensure 100% accuracy for CFO-facing data (preventing hallucinations in balance reporting).
2.  **Azure Architecture:** Designing a scalable RAG pipeline using Azure AI Search and Document Intelligence.
3.  **Complex Data Parsing:** Strategies for extracting structured data from varied bank statements (ISO 20022 vs. legacy formats).
4.  **Agentic Financial Workflows:** Using Durable Functions to manage long-running payment approval or investigation loops.
5.  **Trust & Security:** Data isolation patterns in a multi-tenant treasury environment.
6.  **Observability & Evals:** How to measure the "accuracy" of a conversational treasurer assistant.

## The "CFO Trust" Challenge
*Bonus point requirement:* How to build an assistant that earns the trust of a CFO?
- **Keywords:** Traceability, Grounding, Deterministic fallback, Security, Auditability.
