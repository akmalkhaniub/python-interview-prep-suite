# Job Description Analysis: Full-Stack Engineer - GNO Partners

## Role Overview
**Company:** GNO Partners
**Position:** Full-Stack Engineer
**Level:** Mid-Level (3-5 years)
**Core Mission:** Building end-to-end reporting and optimization tools for Amazon sellers, moving from manual CSV workflows to automated API integrations.

## Core Competencies

### 1. End-to-End Product Development
- **Feature Ownership:** Building tools from the ingestion layer (CSV/API) to the user-facing React dashboard.
- **Workflow Translation:** Turning complex "Amazon Seller" logic into clean software.
- **Reporting:** Aggregating data from multiple sources and generating bulk operation files (for Amazon updates).

### 2. Modern Full-Stack Stack
- **Backend:** TypeScript, Node.js, **NestJS**.
- **Frontend:** React.
- **Database:** Postgres / Supabase (Focus on modeling and scalable queries).

### 3. Cloud & Data Plumbing (AWS)
- **Services:** S3 (for report storage), Lambda (for processing), SNS/SQS (for async tasks).
- **Automation:** Transitioning to **Amazon SP-API** and **Ads API**.

### 4. Agentic AI & Analytics
- **AI Integration:** Basic familiarity with LLM tool-use, prompts, and agent workflows to layer "Insights" on reports.

## Key Interview Themes to Prepare

1.  **Report Aggregation Logic:** How do you handle large CSV/Excel files and merge them with existing database records without performance degradation?
2.  **NestJS & Postgres Design:** Walk through your approach to modeling "Amazon Orders" and "Advertising Campaigns" in a multi-tenant environment.
3.  **Full-Stack Feature Walkthrough:** Describe building a feature like "Automated Bid Adjuster" from API to UI.
4.  **AWS Asynchronous Workflows:** Using Lambda and SQS to process background reports while keeping the UI responsive.
5.  **Agentic AI for Sellers:** How would you use an LLM to suggest a seller "Reduce price on SKU-123 due to high competition"?
6.  **Pragmatic Ownership:** Discuss a time you had to make a technical decision with incomplete information or under a tight deadline.

## Technical "Must-Haves" for the Interview
- 3+ years of **TypeScript/Node.js** experience.
- Proficiency in **NestJS** and **React**.
- Strong **Postgres** modeling and query skills.
- Basic understanding of **AWS Serverless** (Lambda/S3).
