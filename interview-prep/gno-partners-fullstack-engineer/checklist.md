# 7-Day Interview Prep Checklist: Full-Stack Engineer (GNO Partners)

## Day 1: NestJS & Backend Architecture
- [ ] Review **NestJS Modules, Services, and Controllers**.
- [ ] Practice building a simple **CSV Upload API** that saves to S3.
- [ ] Study **NestJS Validation Pipes** and DTOs.

## Day 2: Postgres Modeling & Queries
- [ ] Review **One-to-Many and Many-to-Many** relationship modeling for Sellers/SKUs.
- [ ] Practice writing **Aggregated Queries** (e.g., total sales by SKU over time).
- [ ] Study **Query Profiling** using `EXPLAIN ANALYZE`.

## Day 3: AWS Plumbing (S3/Lambda/SQS)
- [ ] Review **AWS SDK v3 for Node.js** basics.
- [ ] Practice creating a **Lambda function** triggered by an S3 upload.
- [ ] Study **Dead Letter Queues (DLQ)** in SQS for handling failed processing tasks.

## Day 4: React & Data Visualization
- [ ] Review **TanStack Table** for building performant data grids.
- [ ] Practice building a simple **Recharts** dashboard for sales trends.
- [ ] Study **React Performance Hooks** (useMemo, useCallback).

## Day 5: Amazon API & CSV Logic
- [ ] Research the difference between **Amazon SP-API and Ads API**.
- [ ] Practice writing a **CSV streaming parser** in Node.js.
- [ ] Study the **"Bulk Operations"** workflow in Amazon Seller Central.

## Day 6: AI Insights & Agent Basics
- [ ] Experiment with building a simple **LLM-powered insight generator** using Claude.
- [ ] Review **LangChain basics** (Chains, Tools).
- [ ] Practice writing a prompt for **Financial Data Summarization**.

## Day 7: Pitch & Pragmatic Ownership
- [ ] Finalize your **Full-Stack success stories**: Ownership, async collaboration, scaling.
- [ ] Prepare your "Product-Aware Engineer" pitch: How do you translate seller workflows into code?
- [ ] Mock interview: Architect an **End-to-End Report Aggregator** in 10 minutes.
