# AI Engineer (Agentic Workflow Automation) at Halian

## About the job
**Location:** Abu Dhabi / Dubai, United Arab Emirates (Onsite / Hybrid)
**Hiring Agency:** Halian (Recruiting for a tier-1 banking/enterprise institution in the UAE)

### Role Overview
We are looking for a Senior AI Engineer specializing in Agentic Workflow Automation (AWA). In this role, you will design, implement, and orchestrate complex, stateful multi-agent systems and connect them to core banking architectures and customer interfaces.

The focus of this role is on engineering reliability and resiliency into LLM-driven workflows. You will design agent graphs, implement durable workflow orchestrations, define Human-in-the-Loop (HITL) policies, and construct robust error-handling mechanisms (such as circuit breakers and compensating transactions) to ensure high-availability AI systems.

---

### Core Responsibilities
- **Agentic Design:** Architect and construct stateful multi-agent graph topologies using LangGraph, utilizing custom state interfaces, conditional routing, and checkpoint-based recovery.
- **Workflow Orchestration:** Utilize Orkes Conductor (or Temporal) to define, deploy, and monitor long-running, distributed, and durable AI workflows.
- **Human-in-the-Loop (HITL) Integration:** Establish secure wait states and checkpointing logic to allow human operators to review, approve, or reject agent actions before state resumption.
- **Enterprise System Integration:** Serve as the core bridge connecting AI gateways, LLM endpoints, semantic memory indexes, and transactional databases.
- **Resiliency & Fault Tolerance:** Implement transaction safety patterns including exponential backoff, circuit breakers, idempotency constraints, and automatic rollbacks/compensations.
- **AI Infrastructure & MLOps:** Deploy and scale agent workloads on Microsoft Azure (Azure AI Foundry, Azure Kubernetes Service - AKS) and manage CI/CD pipelines via Azure DevOps.

---

### Must-Have Technical Stack & Qualifications
- **Programming Language:** Strong command of Python and backend systems architecture.
- **Agentic Frameworks:** Expert-level knowledge of LangGraph (including state graphs, tokenizers, custom node states, and thread checkpointing).
- **Workflow Engines:** Hands-on experience with Orkes Conductor (Conductor OSS) or Temporal for stateful execution management.
- **Cloud Platform:** Experience deploying workloads on Microsoft Azure (specifically Azure AI Foundry / Azure OpenAI Service).
- **Infrastructure:** Docker, Kubernetes (AKS), and Azure DevOps pipelines.
- **Preferred Certification:** Microsoft Certified: Azure AI Engineer Associate is a strong plus.
- **Experience:** 5+ years of software development experience, with at least 2+ years deploying production-grade AI agents or MLOps systems.
