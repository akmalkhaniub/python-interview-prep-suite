# 7-Day Interview Prep Checklist: Senior Engineer (Smart Working)

## Day 1: Foundational Deep Dive
- [ ] Review Capacitor core architecture and lifecycle.
- [ ] Brush up on React + TypeScript best practices for mobile (Performance, Hooks).
- [ ] Read the official Capacitor "Getting Started" and "Web to Native" guides.

## Day 2: Migration Strategy & Legacy Systems
- [ ] Study Angular/Ionic basics (if not familiar) to understand the legacy stack.
- [ ] Draft a migration plan: How to move from `@ionic/angular` to `@capacitor/core` + React.
- [ ] Research "Strangler Fig Pattern" for incremental UI migrations.

## Day 3: Native Integration & Custom Plugins
- [ ] Practice building a simple Capacitor native bridge (e.g., a native toast or haptic feedback plugin).
- [ ] Understand how to handle iOS/Android permissions (Camera, Location, Push).
- [ ] Review Capacitor's `Capacitor.nativePromise()` and bridge communication.

## Day 4: App Store & Release Workflows
- [ ] Refresh knowledge on iOS App Store Connect and Google Play Console.
- [ ] Review the end-to-end process: Signing -> Archiving -> Uploading -> Review.
- [ ] Study Fastlane basics for automating mobile deployments.

## Day 5: Scale, Concurrency & Performance
- [ ] Practice identifying race conditions in React state (e.g., multiple rapid API calls).
- [ ] Study techniques for handling traffic spikes (Caching, Debouncing, Optimistic UI).
- [ ] Review mobile-specific performance bottlenecks (JS Execution time, Reflows in WebView).

## Day 6: Security, Payments & Firebase
- [ ] Review Stripe integration patterns for mobile.
- [ ] Study Firebase Auth and Cloud Messaging (FCM) setup for Capacitor.
- [ ] Refresh on secure storage practices for JWTs and PII.

## Day 7: Soft Skills & Mock Interview
- [ ] Prepare "Behavioral" stories: Times you took ownership, handled production crises, or worked autonomously.
- [ ] Review the Smart Working mission and mission-alignment.
- [ ] Conduct a mock architectural interview: "How would you design a scalable cross-platform checkout system?"
