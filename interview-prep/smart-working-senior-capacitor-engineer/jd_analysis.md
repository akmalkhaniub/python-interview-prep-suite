# Job Description Analysis: Senior Engineer (React + Capacitor) - Smart Working

## Role Overview
**Company:** Smart Working
**Position:** Senior Engineer (Cross-Platform Application Stack)
**Focus:** React, Capacitor, Mobile App Migration (Angular/Ionic to React).
**Autonomy:** High; required to operate independently for 1-2 days without guidance.
**Shifts:** 12:00 PM - 9:30 PM IST (Summer) | 1:00 PM - 10:30 PM IST (Winter).

## Core Competencies

### 1. Cross-Platform Mobile Development
- **Frameworks:** React + Capacitor (Strict requirement).
- **Migration:** Leading the transition from legacy Angular/Ionic apps to a modern React architecture.
- **UI/UX:** Designing and implementing high-quality, user-focused interfaces.

### 2. App Release & Lifecycle Management
- **Platforms:** iOS (Apple App Store) and Android (Google Play).
- **Workflows:** Provisioning, signing, and deployment.
- **Constraints:** Understanding mobile lifecycle, permissions, and platform-specific constraints.

### 3. Backend & API Integration
- **APIs:** REST APIs and third-party integrations.
- **Security:** Authentication, secure data handling, and payment flows (e.g., Stripe).
- **Backend:** Light backend work with Node.js (minor services, API integrations).

### 4. Production Engineering at Scale
- **Performance:** Scalability and reliability during high-traffic/peak usage.
- **Debugging:** Handling concurrency, race conditions, and edge cases in production.
- **Infrastructure:** Firebase (Auth, Push Notifications), CI/CD, and monitoring tools.

## Key Requirements
- **Technical:** Strong TypeScript and React experience.
- **Experience:** Proven track record of shipping apps to stores via Capacitor.
- **Soft Skills:** Senior-level ownership, accountability, and ability to self-direct in a fast-paced environment.

## Interview Themes to Prepare
1. **Migration Strategy:** How to incrementally migrate a large-scale Angular/Ionic codebase to React + Capacitor without disrupting production.
2. **Capacitor Native Bridges:** Implementing custom Capacitor plugins for platform-specific functionality not available in the core API.
3. **App Store Resilience:** Managing the end-to-end release process, including handling rejections and managing provisioning profiles/certificates.
4. **Performance at Scale:** Identifying and resolving race conditions or performance bottlenecks in a high-throughput mobile application.
5. **Secure Payment Flows:** Implementing PCI-compliant payment integrations (e.g., Stripe) within a Capacitor environment.
6. **Firebase Integration:** Setting up robust push notification systems and authentication flows across both iOS and Android.
