# Smart Working - Anti-Bot Engineer Prep

This module contains preparation materials for the **Anti-Bot Engineer** (Senior Web Scraping Systems) role at Smart Working. The curriculum covers high-scale distributed scraping architectures, proxy orchestration, browser networking internals, and bypass principles for advanced bot detection systems (Cloudflare, Akamai, Datadome).

- [JD.md](file:///g:/ReplitProjects/telemedicine/python-engineer-notebooks/interview-prep/smart-working-anti-bot-engineer/JD.md): The job description and core requirements.
