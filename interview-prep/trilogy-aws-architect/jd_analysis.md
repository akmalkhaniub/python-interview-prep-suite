# Job Description Analysis: AWS Architect - Trilogy (Crossover)

## Role Overview
**Company:** Trilogy (via Crossover)
**Position:** AWS Architect (SRE/DevOps Focus)
**Experience:** Managing hundreds of containers and multi-engine databases.
**Compensation:** $100,000 USD/year ($50/hr).
**Core Mission:** Systematizing reliability across 50+ acquired SaaS products. Restoring order to undocumented, unstable AWS environments.

## Core Competencies

### 1. Deep AWS Infrastructure
- **Platform:** Pure AWS (other clouds are secondary).
- **Scale:** Hundreds of containers (ECS/EKS/Docker).
- **Reliability:** Uptime > 99.9%.

### 2. Automation & Scripting
- **Languages:** Production-grade Python and Bash.
- **IaC:** Terraform, Ansible, or CloudFormation.
- **AI-Assisted:** Leveraging AI agents/tools to explore and document unknown systems 5-10x faster.

### 3. Database Management & Migration
- **Engines:** MySQL, PostgreSQL, Oracle, MS-SQL.
- **Initiatives:** Sophisticated migrations and consolidations.

### 4. Incident Response & RCA
- **Methodology:** 5-Whys Root Cause Analysis (RCA).
- **Deliverables:** Permanent fixes, production-ready automations, and authoring runbooks.
- **Authority:** Ability to apply immediate fixes during incidents and stop unsafe changes.

## Key Interview Themes to Prepare

1.  **Exploring Unfamiliar Systems:** How do you map out an inherited AWS environment with zero documentation? (Mention AI tools and systematic discovery).
2.  **The 5-Whys Analysis:** Be ready to walk through a complex production failure and how you traced it to a single preventable root cause.
3.  **Safe Production Rollouts:** Architecting deployment paths (Dev -> Staged -> 10% -> 100%) with soak periods and rollback conditions.
4.  **Multi-engine DB Migrations:** Challenges and strategies for moving between different database engines (e.g., Oracle to PostgreSQL).
5.  **Infrastructure as Code (IaC) at Scale:** Managing state and complexity across dozens of different product portfolios.
6.  **Monitoring vs. Observability:** Constructing monitors that detect "edge cases" rather than just "CPU is high."

## Technical "Must-Haves" for the Interview
- Real-time troubleshooting skills.
- Ability to produce "copy-paste-ready" runbooks.
- Strict scope discipline (breaking projects into one-day increments).
- Expert-level Python scripting for AWS administration (Boto3).
