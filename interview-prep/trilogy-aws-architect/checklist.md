# 7-Day Interview Prep Checklist: AWS Architect (Trilogy)

## Day 1: AWS Infrastructure Mastery
- [ ] Review **ECS and EKS** at scale (Service discovery, auto-scaling, health checks).
- [ ] Study **VPC Networking** in detail (Peering, Gateways, Transit Gateway).
- [ ] Practice explaining **Route 53 Weighted Routing** for 10% canary rollouts.

## Day 2: Python & Bash for Administration
- [ ] Review **Boto3** sessions, clients, and resource walkers.
- [ ] Write a Python script to crawl a multi-account AWS environment and report unencrypted RDS instances.
- [ ] Practice writing **Bash scripts** for common log parsing (awk, sed, grep).

## Day 3: IaC & Automation
- [ ] Review **Terraform** state management, modules, and providers.
- [ ] Practice writing a modular Terraform script for an **Aurora PostgreSQL** cluster.
- [ ] Research **Ansible** playbooks for server configuration and patch management.

## Day 4: Database Migrations
- [ ] Study **AWS DMS** (Change Data Capture, SCT, and Data Validation).
- [ ] Review **Heterogeneous migration** steps (e.g., Oracle to PostgreSQL).
- [ ] Research **RDS Performance Insights** for query tuning.

## Day 5: Incident Response & RCA
- [ ] Practice the **5-Whys methodology** on 3 past production incidents.
- [ ] Draft a "copy-paste-ready" **Runbook** for a common issue (e.g., 502 Bad Gateway).
- [ ] Study **CloudWatch Logs Insights** syntax for rapid troubleshooting.

## Day 6: AI-Assisted Operations
- [ ] Experiment with using LLMs to generate **Terraform** and **Boto3** code.
- [ ] Use AI to analyze a sample log file and suggest potential root causes.
- [ ] Practice "Independent System Discovery" using AI agents and standard CLI tools.

## Day 7: Pitch & Behavioral Review
- [ ] Refine your "Independent Contractor" pitch: High-autonomy, 40 hrs/week, solution-focused.
- [ ] Prepare for the **"Real-time Troubleshooting"** screen: How do you communicate your thoughts while debugging?
- [ ] Final review of the **Trilogy mission** and the **AWS Reliability** deep-dives.
